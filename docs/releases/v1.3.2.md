# Passport 1.3.2

Mac ARM64용 터미널 표시 수정과 작업 탭 아이콘 확장입니다. Windows 최신 공개 설치본은 [1.3.1](https://github.com/poyal/passport/releases/tag/v1.3.1)이며, Windows 1.3.2는 같은 소스로 별도 검증한 뒤 배포합니다.

## 터미널 표시 수정

- zsh·agnoster의 `💻`·`🔧` 같은 단일 이모지 프롬프트에서 긴 입력을 편집할 때 잔상과 커서 위치가 어긋나던 문제를 수정했습니다. [이슈 #7](https://github.com/poyal/passport/issues/7).
- 모든 터미널의 첫 출력과 화면 복원 전에 Unicode 11 문자 폭 계산을 적용합니다. 로컬·SSH와 일반·대체 화면에 같은 설정을 사용합니다.

## 로컬 아이콘 56개

**탭 설정 → 아이콘 → 로컬**에서 AI 도구와 개발 작업을 구분할 수 있습니다.

- **AI 도구 16개:** ChatGPT/GPT, Codex, Claude, Gemini, GitHub Copilot, Cursor, Ollama, OpenCode, Cline, DeepSeek, Grok, Perplexity, Qwen, Hugging Face, LM Studio, Windsurf.
- **개발 도구 12개:** GitHub, GitLab, VS Code, IntelliJ IDEA, Neovim, Docker, Kubernetes, Postman, Jenkins, Terraform, Vercel, Figma.
- **언어·프레임워크 12개:** Python, JavaScript, TypeScript, Node.js, React, Vue.js, Next.js, Go, Rust, Java, Kotlin, Swift.
- **데이터·인프라 8개:** PostgreSQL, MySQL, SQLite, Redis, MongoDB, Supabase, Firebase, Nginx.
- **기본 작업 8개:** 터미널, 프로젝트, 코드, Git, 컨테이너, 데이터베이스, 브라우저, 패키지.

영문 이름과 `지피티`, `파이썬`, `도커` 같은 한글 별칭으로 검색하거나 분류를 골라 찾을 수 있습니다. **적용**한 아이콘은 재시작·템플릿·백업에 보존됩니다. SVG를 앱에 포함해 오프라인에서도 표시합니다.

## 업데이트와 알려진 제한

Passport를 완전히 종료한 뒤 Mac DMG의 앱으로 업데이트하세요. 기존 호스트·설정·작업 배치는 유지됩니다. 새 로컬 아이콘이 포함된 백업은 **1.3.2 이상**에서 가져오세요.

긴 국기 이모지·분해 한글·ZWJ 조합 프롬프트와 일부 분해 한글 입력에는 셸과 터미널의 폭 계산 차이가 남아 있습니다. 단일 이모지 문제의 수정으로 모든 복합 문자 문제가 해결된 것은 아닙니다.

Mac 설치본은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. Windows 실기와 물리 IME, 실제 AI 서비스 동작은 별도 검증 대상입니다.
