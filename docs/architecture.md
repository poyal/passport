# Passport 0.3 구현 구조

## 프로세스와 권한

메인 프로세스가 모든 앱 창의 SSH·로컬 셸·파일 연결·터널·전송·데이터를 관리한다. 렌더러에는 Node 접근을 허용하지 않고 context isolation, sandbox, CSP를 적용한다. 화면은 제한된 `passport://app/` 프로토콜로 읽는다. 외부 탐색·웹뷰·웹 콘텐츠의 창 생성·임의 권한 요청은 차단한다. 앱 내부의 창 이동 요청만 메인에서 새 BrowserWindow를 만든다.

preload는 타입이 정해진 호출과 이벤트만 노출한다. 메인은 송신 창과 메인 프레임, Zod 입력 스키마, 세션/파일 연결의 소유 창을 검증한다. 문서 revision을 비교해 다른 창의 최신 변경을 오래된 문서로 덮어쓰지 않는다. 설정·인증 프로필 메타데이터 변경은 모든 창에 전달한다. 업데이트·동기화 서버는 없다.

## 세션·버퍼·창 이동

분할 배치는 `Pane | Split` 이진 트리이며 패널 ID가 세션 ID다. `Sessions`는 SSH, `LocalSessions`는 node-pty 프로세스를 관리한다. 렌더러의 registry는 xterm 인스턴스와 스크롤백을 보관해 탭 이동·분할·집중 보기에서 재사용한다. 로컬 셸은 설치된 기본 셸과 플랫폼별 후보만 실행한다.

출력은 작은 묶음으로 보내고 xterm 쓰기 완료 시 ACK를 받는다. 미처리 출력이 256KiB에 도달하면 SSH 스트림/PTY 읽기를 멈추고 소비 후 재개한다. SSH 자동 재접속은 기존 명령이나 시작 스니펫을 다시 실행하지 않는다. 환경 변수는 SSH shell 요청에 전달하며 서버의 AcceptEnv 정책을 따른다.

로컬 탭을 닫아도 PTY의 비동기 종료 콜백이 끝날 때까지 추적한다. 이전 연결의 지연된 콜백이 같은 패널의 새 연결 상태를 바꾸지 않도록 인스턴스를 비교한다. 앱 종료 시에는 모든 PTY 종료와 콜백 반환을 기다린 뒤 DB와 Electron을 종료한다. 일반 종료 신호를 무시하는 셸에는 1초 뒤 강제 종료 신호를 보내되, 실제 종료 확인 없이 Node 환경을 먼저 해제하지 않는다.

별도 창 이동 시 새로운 출력을 잠시 큐에 보관하고, 원래 창의 xterm 쓰기가 끝난 뒤 SerializeAddon으로 상태를 직렬화한다. 소유 창을 변경하고 대상 창에 버퍼·세션 외형·상태·대기 출력을 순서대로 전달한다. 버퍼 재생 중 생성되는 터미널 응답은 원격으로 보내지 않는다. 연결은 메인에 그대로 있고, 실패/시간 초과에는 원래 창으로 출력을 되돌린다. 이동 중 배치 변경은 잠시 막는다. 창 재로드·종료는 해당 창이 소유한 연결을 정리한다.

동시 입력은 현재 작업 탭에서 선택한 SSH 세션에만 적용한다. 실제 키 입력/IME 이벤트만 복제하고 터미널 응답이나 원격 출력을 복제하지 않는다. 탭 전환·도구 닫기·창 이동 시 해제한다. 붙여넣기는 대상 ID를 고정해 미리보기 후 전달하며, 실행 미리보기의 실행 버튼만 Enter를 추가한다. 변수는 문자열 치환이며 로컬에서 평가하지 않는다.

## 외형과 출력 강조

외형 우선순위는 세션 임시값 → 호스트 → 가까운 그룹부터 상속한 값 → 전체 기본값이다. 사용자 색상은 엄격한 팔레트 스키마로 저장하며 외부 실행 코드를 포함하지 않는다. 출력 강조는 현재 보이는 행에만 xterm decoration을 적용하고 원문 버퍼를 수정하지 않는다. 서버가 지정한 전경/배경색을 우선하며 대체 화면에는 적용하지 않는다. 바뀌지 않은 색상 구간의 decoration은 재사용하고, 새 출력은 파싱 직후 다음 화면 그리기 전에 반영한다. 스크롤·리사이즈 갱신은 프레임별로 묶는다. 외형 설정도 값이 달라졌을 때만 적용한다.

## 터널·파일 전송

`Tunnels`는 규칙별 SSH 연결과 TCP 소켓을 소유한다. 로컬 forwardOut, 원격 forwardIn, SOCKS5 CONNECT의 IPv4/도메인/IPv6 요청을 처리한다. TCP 스트림의 역압력을 유지하고 중지 시 서버·소켓·SSH 연결을 해제한다. 인증 정보·호스트 지문 확인은 일반 SSH와 공유한다. 접속 경유용 프록시·점프 호스트는 범위에 없다.

`FileAdapter`는 로컬·SFTP·FTP/FTPS 목록·메타데이터·관리·스트림을 통합한다. 좌우 패널은 독립 연결이다. 같은 엔드포인트를 사용하는 작업은 직렬화하고 최대 세 전송을 진행한다. 원본에서 대상 임시 파일로 스트리밍한 뒤 크기를 검증하고 최종 이름으로 바꾼다. 덮어쓸 원본의 임시 백업을 남겨 실패 시 복원한다. 취소·실패 시 임시 파일 정리 결과를 표시한다.

재귀 전송에서 심볼릭 링크를 건너뛰고 동일 경로·자기 하위 폴더 복사를 차단한다. 재시도는 처음부터 진행한다. 끊긴 패널을 같은 호스트에 재접속하면 작업의 연결 참조를 갱신한다. FTPS 인증서 검증을 비활성화하지 않는다.

## 저장·로그·이식

SQLite 스키마 2는 메타데이터 문서·인증 프로필·호스트 지문·로그 인덱스·명시적 실행 이력을 분리한다. v0.1 메타데이터에 없는 후속 필드는 기본값으로 읽으며 이전 앱의 DB 쓰기를 차단한다. 인증 비밀값은 safeStorage로 보호하고 사용 불가 시 저장하지 않는다. 앱 시작·목록 조회에서는 OS 비밀 저장소에 접근하지 않는다.

세션 로그는 사용자가 기록을 켠 출력만 별도 로컬 파일에 저장한다. 기본 30일/전체 1GiB 한도로 오래된 기록을 제거한다. 검색은 최대 256KiB 청크를 읽고 한 요청당 최대 16MiB를 탐색한다. 북마크는 바이트 위치와 이름을 저장한다. 명령 이력은 앱의 실행 버튼으로 보낸 명령만 수집하며 200개로 제한한다. 원격 출력의 민감정보를 자동 제거한다고 보장하지 않는다.

수동 내보내기는 기존 버전 1 JSON에 후속 설정을 포함한다. 비밀값은 기본 제외하며, 포함 시 scrypt와 AES-256-GCM으로 별도 암호화한다. 가져오기 미리보기는 비밀값을 반환하지 않고 5분 뒤 만료된다. 적용은 트랜잭션이며 새 기기의 OS 암호화로 다시 저장한다. 로컬 시작 경로는 재지정하고 미설치 폰트·셸은 기본값으로 대체한다. 연결·실행 중 터널·로그 파일·명령 이력은 내보내지 않는다.

## 네이티브 패키징

Mac은 arm64만 빌드한다. Windows는 x64와 ARM64를 별도 네이티브 CI 작업으로 구성한다. better-sqlite3와 node-pty를 대상 Electron ABI에 맞춰 빌드하고 PTY helper를 asar 밖에 포함한다. 패키지 검증은 초기 화면, 로컬 PTY 실행·입력, 프로세스 종료 코드 0과 종료 시그널 없음을 확인한다. Windows ARM64 runner 선택 근거는 [GitHub 공식 runner 목록](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)이다. 실제 플랫폼별 실행 여부는 검증 기록을 따른다.
