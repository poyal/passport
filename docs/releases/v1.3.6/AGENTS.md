# Passport 1.3.6 검증 기록

## 범위와 소스

Mac ARM64만 게시하는 1.3.6 후보입니다. Windows 1.3.6은 검증·게시 대상이 아니며 공개 Windows 설치본은 1.3.5를 유지합니다. 정식 소스는 검증을 통과한 `v1.3.6` 태그 커밋으로 확정합니다.

일반 텍스트 HTTP/HTTPS 주소를 기존 링크 확인·브라우저 열기 경로에 연결합니다. 표·괄호 안의 주소, 자동 줄바꿈된 주소와 명시적 하이퍼링크의 실제 목적지를 함께 검사합니다. 이전 Mac 1.3.5 이후 반영된 좁은 세션 로그 화면의 읽기 영역 보장과 화면 재로드 후 빈 터미널이 저장된 이력을 덮어쓰지 않도록 한 수정도 포함합니다.

## 검증·공개 상태

첫 후보 `86bc634`는 단위·통합 273개와 릴리즈 정책 78개를 통과했지만 소스 GUI의 기존 터미널 복원 적용 검사에서 실패했습니다. Passport 터미널 안에서 앱을 시작했을 때 부모의 `PASSPORT_RESUME` 등이 새 PTY에 상속되어 복원 연동을 잘못 판단하는 원인을 확인했습니다. 새 PTY에서 이전 세션의 인증·AI 실행·복원·시작 로더 환경을 제거하고 해당 부모 환경을 명시한 회귀 검사를 추가했습니다. 실패한 후보의 결과는 게시에 사용하지 않습니다.

수정 후보 `fc556d3`의 첫 정식 실행은 소스 숨김 GUI를 통과했지만 데스크톱 알림의 전경 조건에서 실패했습니다. 같은 소스의 단독 사례와 전체 데스크톱 4개 진단은 통과했으며, 외부 포커스 변경 여부 등 정확한 원인은 확정하지 못했습니다. 다음 정식 실행은 소스 숨김·데스크톱, DMG·서명·설치본 smoke를 통과한 뒤 설치본의 마지막 일반 셸 재연결에서 CLI 결과 파일 대기가 실패했습니다. 같은 설치본의 단독 반복 진단 10회는 통과했습니다. 프로파일 없는 셸은 환경 상태가 ready여도 첫 프롬프트 전일 수 있으므로, 재연결 시험을 각 세션 세대의 고유한 실제 프롬프트를 확인한 뒤 입력하도록 보완했습니다. 실패한 두 실행이나 부분 진단은 정식 검증으로 대체하지 않습니다.

보완 후보의 전체 정식 검증·DMG 게시·공개 다운로드 확인은 대기 중입니다. 사용자는 이번 Mac 릴리즈의 실제 데스크톱 검사를 허용했습니다.

`268868e`의 두 정식 실행은 새 DMG 후보의 키체인 승인 대기로 설치본 GUI가 시간 초과됐습니다. 두 실행 모두 `SecItemCopyMatching` 호출 스택으로 확인했으며 사용자 승인 후 해당 후보의 실제 암호화·재시작 진단은 통과했습니다. 새 후보마다 승인 창이 다시 나타나므로 설치 파일 단계에 실제 키체인 암호화·복호화 준비를 추가했습니다. OS 승인 준비는 최대 180초이며 GUI 검사·정상 종료 제한은 유지합니다. 준비 단계의 실패 조건 회귀 검사와 승인된 실제 DMG 진단을 통과했습니다.

`8ed40e0`는 소스 전체와 DMG 내부 숨김 GUI 97개까지 통과했지만 설치본 데스크톱의 전경 알림 검사에서 실패했습니다. 전체 데스크톱 순서의 별도 진단에서 CLI 실행 직후 네이티브 blur와 알림 시점의 전경 창 부재를 기록해 재현했습니다. 고정 대기만으로는 재발해 채택하지 않았습니다. 모의 CLI가 준비 신호를 보낸 뒤 실제 네이티브·renderer 포커스를 확인하고 알림을 방출하도록 시험을 동기화했습니다. 알림 발생 중 강제 포커스·네이티브 포커스 mock·시험 생략은 추가하지 않았습니다. 같은 설치본의 전체 데스크톱 순서 3회(12개)가 통과했으며 최종 정식 실행은 별도로 수행합니다.

Mac 앱은 기존 ad-hoc 서명을 사용하며 Developer ID·Apple 공증은 포함하지 않습니다. Windows 실기·설치 파일, 물리 IME, 다른 PC와의 LAN, 실제 AI 서비스, 깨끗한 계정의 설치·제거·업그레이드와 선택 검사는 별도 범위입니다.

사용자 매뉴얼은 [1.3.6 README](README.md), 공통 절차는 [개발 가이드](../../development.md)와 [릴리즈 가이드](../../release.md)를 따릅니다. 매뉴얼 화면은 기존 1.3.5·1.3.1 촬영본을 재사용합니다.
