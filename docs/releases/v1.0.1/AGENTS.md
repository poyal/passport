# Passport 1.0.1 AI 기록

원본 공개 태그 `v1.0.1`의 소스는 `27b68a5a31bd3c52c9e4b418a56f664ebebd7247`입니다. [사용자 매뉴얼](README.md)과 [공통 릴리즈 절차](../../release.md)를 참고하세요.

2026-10-20 Windows 누락 설치본을 확인하며 원본 태그의 의존성·타입·빌드를 준비했습니다. Windows 11 x64, Node 24.14.0, npm 11.21.1, Electron 44.4.5, Python 3.13.7, MSVC Build Tools 2022에서 실행했습니다. 파일 전송 시험의 심볼릭 링크 생성에 필요한 관리자 권한을 사용자가 허용한 뒤, 같은 소스의 FTP/FTPS 포함 단위·통합 검사는 89 통과·플랫폼 및 선택 검사 3 생략으로 완료했습니다.

원본 GUI의 `updates.spec.ts`는 모의 GitHub 응답에 Mac DMG만 제공하고 다운로드 결과도 Mac URL로 고정합니다. Windows에서는 설치 파일이 없는 것으로 판정되어 첫 업데이트 사례가 실패했습니다. 전체 실행 결과는 20 통과·1 실패·2 생략·10 미실행입니다. 이 결과를 앱 업데이트 기능 자체의 결함이나 검증 통과로 해석하지 않습니다.

사용자는 2026-10-20 이 구버전의 추가 수정을 보류하고 Windows 1.3.5 게시를 완료하도록 선택했습니다. 따라서 Windows 1.0.1 설치 파일을 게시하지 않았고 기존 공개 태그·Mac 파일을 유지했습니다. 다시 진행하려면 시험의 플랫폼별 응답·기대값을 바로잡고 소스 출처를 구분한 뒤 전체 검증이 필요합니다. 현재 파이프라인의 검증 manifest는 이 구버전에 존재하지 않습니다.
