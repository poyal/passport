# Passport 1.3.10 검증 기록

2026-11-09 [v1.3.10](https://github.com/poyal/passport/releases/tag/v1.3.10)을 Mac ARM64·Windows x64로 공개했습니다. 두 설치 파일과 태그의 소스는 `92d624ddbbb14f54989114ed305c877e18266e29`입니다. 검증한 파일을 재빌드 없이 함께 게시했습니다. 이 결과를 확정한 후속 문서 커밋은 배포 바이너리의 소스가 아닙니다.

사용법은 [1.3.10 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

## 키체인 실패와 재검증

초기 Mac 숨김 preview는 SSH Background 세션의 키체인 접근 제한으로 실패했습니다. GUI 로그인 세션의 앞선 정식 실행들도 사용자 승인 전에 180초 준비 제한과 10초 정상 종료 제한을 넘어 실패했습니다. 해당 결과를 성공으로 바꾸거나 승인·종료 제한을 늘리지 않았습니다.

사용자가 Mac의 Passport 요청을 직접 승인한 뒤 기존 후보의 실제 암호화·복호화와 정상 종료를 확인하고, 전체 정식 검증을 새 실행 ID로 다시 수행했습니다. 최종 위 실행은 새 DMG 내부 후보의 키체인 준비·정상 종료와 모든 설치본 검사를 통과했습니다. HOME·키체인 잠금·접근 제어를 바꾸거나 평문 mock으로 우회하지 않았습니다.

## 검증 범위와 제한

물리 한글 IME 조합, 최소 지원 macOS 14 실기, 깨끗한 계정의 설치·업그레이드·제거, OS 알림의 실제 전달, 로그인한 외부 AI 서비스, 별도 실제 PC 간 LAN·Docker·장시간 부하·실제 AI CLI 선택 검사는 이번 릴리즈에서 수행하지 않았습니다. 기존 버전의 선택 검사 결과를 이번 버전의 결과로 복사하지 않았습니다.

Mac은 ad-hoc 서명이며 Developer ID·Apple 공증을 포함하지 않고 Windows EXE에는 Authenticode 서명이 없습니다. 사용자 설치 앱·실제 DB는 교체하지 않았습니다. 매뉴얼은 변경되지 않은 1.3.1·1.3.5 화면을 재사용하며 새 버전 촬영으로 표시하지 않습니다.

공개 다운로드와 최종 문서 확정 후 일회성 작업·LaunchAgent·마운트·격리 프로필·빌드·시험·작업용 도구 산출물을 정리했습니다.
