# Passport 1.3.1

2026-10-17 · Windows x64 / macOS Apple Silicon

## 쪽지로 주고받기

- **쪽지 화면:** 기존 공유함을 쪽지로 바꾸고 메뉴·설정·알림에 같은 이름과 봉투 아이콘을 적용합니다.
- **쪽지 + 첨부:** 본문만 보내거나 파일 하나를 함께 첨부할 수 있습니다. 파일 선택 후 파일명이 표시되며 첨부만 보내기는 제거했습니다. 쪽지와 첨부는 한 번 승인해 함께 받습니다.
- **서식 편집기:** 제목·굵게·기울임·목록·인용·코드와 실행 취소를 지원합니다. Markdown 원문으로도 편집할 수 있습니다.
- **받은 쪽지:** 요청과 수신한 쪽지를 같은 목록에서 확인합니다. 전체·승인 대기·받은 쪽지 필터, 친구·본문 첫 줄·파일명 검색, 목록과 본문의 독립 스크롤을 제공합니다. 승인 대기는 주황색과 시계, 수신 완료는 체크 아이콘으로 구분합니다.
- **받기와 거절:** 대기 항목을 선택해 오른쪽 상세 화면에서 처리합니다. 승인 후에는 같은 자리에서 본문이 열립니다. 첨부는 열기·경로 복사 아이콘으로 확인합니다.
- **친구 관리:** 받는 사람을 검색해 선택하고, 수정 창에서 이름·주소를 함께 바꿉니다. 삭제하면 등록과 인증 신뢰를 제거합니다. 별도 차단 기능은 없으며 이전에 차단한 친구는 목록을 열 때 삭제합니다.
- **사용가이드:** 실제 화면을 포함한 쪽지 안내, Passport CLI 명령, AI에 붙여넣을 안내문과 복사 버튼을 제공합니다. CLI 명령 이름은 `passport share`를 유지합니다.

## 수정 사항

- Mac 주변 검색의 UDP 소켓 바인딩과 비동기 오류 처리를 보완합니다.
- 친구 인증서의 subject가 같아 여러 친구 등록 후 TLS 연결이 실패하던 문제를 수정합니다. 인증서 검증과 기기 지문 확인은 유지합니다.
- Windows에서 수신 파일의 다운로드 보호 정보를 검사할 때 파일 자체를 열지 못하던 문제를 수정합니다.
- 친구 이름만 바꿨을 때 연결을 끊던 동작과, 잘못된 주소를 입력해도 별칭이 일부 저장되던 문제를 수정합니다.
- 전달이 끝난 요청을 취소할 때 CLI가 실제 최종 상태를 반환합니다. 첨부 보호나 쪽지 저장이 실패하면 새 파일을 남기지 않습니다.

## 업데이트와 사용 범위

양쪽 PC를 1.3.1로 업데이트하세요. 쪽지+첨부와 여러 친구 인증서 선택 수정은 양쪽 최신 앱에서 사용합니다. 같은 LAN을 지원하며 VPN은 지원 대상에서 제외했습니다. 등록키는 5분, 수신 요청은 10분 후 만료됩니다. 쪽지 본문은 UTF-8 256 KiB, 첨부는 100 MiB까지입니다.

Passport를 완전히 종료한 뒤 해당 OS 설치본으로 업데이트하세요. 기존 Mac 1.3.0 태그와 설치 파일은 보존합니다. 개발 앱의 샘플 데이터는 정식 앱으로 옮기지 않습니다. Mac은 ad-hoc 서명이며 Apple 공증을 포함하지 않습니다.

받은 본문의 링크·외부 이미지·스크립트는 실행하지 않습니다. 첨부 파일은 자동으로 열리지 않으며 사용자가 열기 버튼을 눌러야 운영체제 기본 앱으로 엽니다. 다운로드 파일은 일반 파일이며 앱 내 쪽지 암호화 보관과 구분합니다.

거절 결과는 정상적으로 처리되지만, 수신자가 직접 거절해도 알림에 ‘상대가 쪽지 요청을 거절했습니다’라고 표시되는 기존 문구는 남아 있습니다.
