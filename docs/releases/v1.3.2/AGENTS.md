# Passport 1.3.2 AI 기록

이 문서는 1.3.2의 배포 소스·검증 환경·최종 결과·남은 제한을 기록합니다. 공통 작업 지침은 [루트 AGENTS](../../../AGENTS.md), 개발·E2E·문서 규칙은 [공통 개발 규칙](../../development.md), 검증·게시·정리 절차는 [릴리즈 가이드](../../release.md)를 따릅니다. 사용자 조작은 [1.3.2 매뉴얼](README.md), 패치 노트는 [GitHub Release](https://github.com/poyal/passport/releases/tag/v1.3.2)에서 확인합니다.

## 버전별 데이터와 화면 기준

1.3.2의 SQLite 스키마는 5, 문서·portable 형식은 2입니다. 매뉴얼 전체 화면은 1.3.1 최종 Mac 앱에서, 앱 내부 쪽지 가이드의 두 부분 화면은 1.3.1 Windows UI에서 격리된 예제 데이터로 촬영했습니다. 변경되지 않은 화면을 재사용하며 1.3.2에서 새로 촬영한 화면으로 표시하지 않습니다.

[이슈 #7](https://github.com/poyal/passport/issues/7)의 `💻`·`🔧` 프롬프트 잔상·커서 위치 불일치는 Mac 1.3.2에서 수정·배포되어 해결 상태로 닫았습니다. 확대 검사 86개 중 81개는 정상이지만, 긴 국기·분해 한글·ZWJ 프롬프트 3개와 분해 한글 입력·붙여넣기 2개는 미해결이며 [후속 이슈 #8](https://github.com/poyal/passport/issues/8)에서 추적합니다. 일반 이모지 폭 수정으로 모든 복합 문자가 해결된 것은 아닙니다.

이전 Electron 종료 지연·사용자 셸 초기화 지연의 최초 원인은 미확정입니다. 후속 검사가 성공했지만 최초 원인의 해결 여부는 확인되지 않았습니다.

물리 IME·실제 AI 서비스·OS 알림·깨끗한 계정의 설치/업그레이드·macOS 14 실기·Developer ID/공증은 위 자동 검사 성공과 별개입니다. 이 항목들은 자동 검사 성공만으로 검증 완료 처리하지 않았습니다.
