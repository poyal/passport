# Passport 1.0.0 릴리즈 안내

배포일: 2026-09-30. [설치 파일](https://github.com/poyal/passport/releases/tag/v1.0.0) · [릴리즈 목록](README.md)

Passport의 첫 1.0.0 릴리스입니다. Apple Silicon Mac용 DMG를 제공합니다.

- 구형 CentOS 5/6의 SSH 키 교환을 자동으로 지원합니다. 최신 서버는 현대 알고리즘을 먼저 선택합니다.
- 설정 화면을 반응형 탭으로 정리했습니다. 외형·인증·가져오기/내보내기·백업·로그 화면을 구분하고 간격을 통일했습니다.
- 아이콘을 지정하지 않으면 호스트 이름과 접속 후 OS 감지로 자동 표시합니다. 사용자가 선택한 아이콘은 유지합니다.
- 모든 테마에서 폴더·실행 파일·심볼릭 링크 이름에 색상을 적용합니다. 색 없는 긴 파일 목록도 구분하며 서버의 기존 ANSI 색상은 유지합니다.
- 창 이동 후 지연된 터미널 크기 조절 이벤트로 오류가 발생하는 문제를 수정했습니다.
- 앱을 다시 열면 탭과 분할 배치를 복원합니다. 서버 연결은 직접 다시 시작합니다.

Mac에서 단위·통합 80개, GUI 시나리오 22개 및 1GiB 연속 출력 시험을 통과했습니다. 출력 시험은 최근 10,000행 스크롤백을 사용했으며 전체 1GiB를 메모리에 보관하는 방식은 아닙니다.

설치는 DMG를 열고 Passport를 Applications로 옮기세요. macOS 14 이상, Apple Silicon(M 시리즈)이 대상입니다. 이 배포는 ad-hoc 서명이며 Apple 공증을 포함하지 않습니다. Windows 설치 파일은 이번 릴리스에 포함하지 않습니다.

구형 SSH 호환에는 SHA-1 키 교환이 포함됩니다. 기존 서버 지문이 바뀌면 연결은 차단되며 지문 교체/신규 자산 화면은 아직 시안입니다. 설치 파일의 무결성은 함께 제공하는 `SHA256SUMS.txt`로 확인할 수 있습니다.
