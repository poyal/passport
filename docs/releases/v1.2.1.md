# Passport 1.2.1

단축키 편집을 간단하게 바꾸고 앱의 버튼 모양과 설정 화면 간격을 맞췄습니다. **macOS 14 이상·Apple Silicon용 DMG와 Windows 11·x64용 EXE**를 제공합니다.

## 주요 변경

- **단축키 변경·해제·초기화:** 기능마다 키 하나를 지정합니다. **설정 → 단축키 → 키 변경**에서 키를 누르고 **적용**한 뒤 **단축키 저장**을 누르세요. **X**는 해제, **초기화**는 해당 기능의 기본 키 복원입니다.
- **키 표시와 버튼 통일:** 키 조합은 텍스트로 표시하며 `키 변경`·X·`초기화`와 앱의 일반 동작 버튼에 같은 배경·테두리·모서리를 사용합니다.
- **설정 화면 간격:** 업데이트 결과와 안내문, 제목과 버튼, 글꼴 라벨과 입력칸, 프로파일·포트 포워딩 대화상자의 간격을 정리했습니다. 작은 창과 다크·라이트 테마에서도 확인했습니다.

## 기존 단축키와 백업

한 기능에 여러 키를 지정했던 설정은 **첫 번째 키만 유지**합니다. 두 OS의 설정과 기존 백업 가져오기에 동일하게 적용하며, 해제한 기능은 그대로 해제 상태를 유지합니다. 업데이트 후 **설정 → 단축키**에서 지정된 키를 확인하세요.

## 업데이트와 확인 범위

Passport를 **완전히 종료**한 뒤 업데이트하세요. Mac은 **⌘Q**로 종료하고 새 DMG의 앱을 응용 프로그램 폴더로 옮겨 **대치**합니다. Windows는 새 EXE를 실행해 현재 사용자에게 설치합니다. 호스트·인증·작업 배치는 유지되며 연결은 다시 시작합니다.

Mac 설치본은 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다. Windows EXE에는 코드 서명이 없습니다. 두 플랫폼은 같은 `v1.2.1` 소스로 각각의 격리된 runner에서 소스·최종 설치본의 숨김 GUI와 데스크톱 검사를 통과했습니다. Windows 설치 범위·네 가지 셸·DPAPI도 확인했습니다. [검증 기록과 설치 파일 해시](https://github.com/poyal/passport/blob/main/docs/verification.md).

사용자 계정 설치·업그레이드, 물리 IME, OS 알림과 외부 AI 서비스는 자동 검사와 별도로 확인합니다.
