# Passport 1.2.0

OS별 단축키와 터미널 링크를 개선하고 Windows 터미널의 종료 정리를 보완했습니다. 배포 대상은 **macOS 14 이상·Apple Silicon**과 **Windows 11·x64**입니다.

## 주요 변경

- **OS별 단축키 설정:** Mac과 Windows의 기본 키와 사용자 지정 키를 따로 저장합니다. 설정에서 키를 변경하거나 해제할 수 있으며 파일 목록의 메뉴·이름 변경·삭제에도 적용합니다. Windows에서 메뉴 키를 해제해도 기본 메뉴가 열리던 문제를 수정했습니다.
- **터미널 링크 열기:** 터미널의 웹 링크를 누르면 실제 목적지를 확인한 뒤 기본 브라우저로 엽니다. 앱 내부 화면 이동과 안전하지 않은 주소는 차단합니다.
- **설정 화면 스크롤:** 작은 창에서도 설정과 단축키 목록을 스크롤해 편집할 수 있습니다.
- **Windows·Mac 기능 분리:** 셸 실행, 클립보드, 창 설정과 네이티브 알림 연결을 OS별로 분리하고 세션·저장·전송 기능은 공통으로 유지합니다.
- **Windows 종료 정리:** 터미널을 닫으면 그 터미널에서 실행한 셸과 자식 프로그램을 함께 종료합니다. 다른 터미널은 유지합니다. 배포 GUI 검사는 실행 후 남은 내장 Bash·ConPTY 프로세스도 확인합니다.

## 업데이트와 확인 범위

Passport를 완전히 종료한 뒤 Mac은 새 DMG의 앱으로 대치하고 Windows는 새 EXE를 실행하세요. 호스트·설정·작업 배치는 유지되며 연결은 다시 시작합니다. Windows ARM64 설치본은 이번 배포에 포함하지 않습니다.

Windows 로컬 숨김 검사와 격리된 Windows·Mac runner의 정식 검증 결과, 설치 파일 해시는 [검증 기록](https://github.com/poyal/passport/blob/main/docs/verification.md)에 기록합니다. Windows는 코드 서명이 없고 Mac은 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다. 실제 사용자 계정 설치·업그레이드, 물리 IME, OS 알림과 외부 AI 서비스 검사는 자동 검사와 구분합니다.
