# Passport 1.3.10 검증 기록

1.3.10 릴리즈 후보를 준비하고 있습니다. Mac ARM64·Windows x64의 정식 검증과 GitHub 게시는 아직 수행하지 않았습니다. 이전 버전의 검사 수·해시는 이번 후보의 결과가 아닙니다.

사용법은 [1.3.10 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

## 후보 변경

`28f4017529883697abb246d887dfe0a6f2f24b29`의 창 닫기 소유권·TUI 마우스 입력 수정을 포함합니다. 여러 창 중 하나를 닫으면 해당 창의 탭을 제거하고 다른 창에 자동 배정하지 않습니다. 마지막 창 닫기와 앱 전체 종료는 탭을 보존합니다. TUI의 일반 마우스 입력과 Shift+우클릭 앱 메뉴를 구분하며 버튼 누름·해제의 처리 대상을 유지합니다.

## 검증 상태와 제한

두 OS는 같은 최종 소스 커밋에서 검증할 예정입니다. 정식 검증, 설치 파일 해시, 공개 다운로드 결과는 실제 수행 후 확정합니다. Mac Developer ID·Apple 공증, Windows Authenticode 서명, 물리 IME, 최소 지원 OS 실기, 깨끗한 계정의 설치·업그레이드·제거, 로그인한 외부 AI 서비스는 아직 검증하지 않았습니다.
