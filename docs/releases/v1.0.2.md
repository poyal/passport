# Passport 1.0.2 수정 안내

작성일: 2026-09-30. 배포 상태와 설치 파일은 [릴리즈 목록](README.md)에서 확인하세요.

터미널 배치를 이름으로 저장하는 **스페이스**를 추가하고 파일 작업 메뉴와 세션 로그·SSH 연결 선택창의 스크롤을 수정했습니다.

- 상단 탭을 **호스트 → 스페이스 → 파일** 순서로 배치했습니다.
- **스페이스 → 현재 창 저장**으로 터미널 탭 순서, 분할 방향·비율과 선택한 터미널을 저장합니다. 저장된 이름을 누르면 기존 탭을 유지한 채 새 탭으로 열고 연결합니다. 배치만 열기, 현재 창으로 갱신, 이름 변경과 삭제도 지원합니다.
- 저장된 스페이스는 앱 재시작 후에도 유지되며 설정 내보내기·가져오기·백업에 포함합니다. 앱 시작과 파일 가져오기는 연결을 자동으로 시작하지 않습니다.
- 파일 **작업** 버튼을 다시 누르면 메뉴가 닫힙니다. Escape·바깥 클릭·파일 목록 스크롤·창 크기 변경으로도 닫을 수 있습니다. 경로 입력창의 커서 스크롤은 메뉴에 영향을 주지 않습니다.
- 세션 로그의 목록과 본문이 창의 남은 높이를 채우도록 수정했습니다. 목록과 본문을 독립적으로 스크롤하며 검색창과 하단 작업 버튼은 유지됩니다. 이전 로그 읽기 응답이 새 선택을 덮어쓰는 것도 막습니다.
- SSH 연결 선택창의 로컬 셸과 열기 버튼을 정렬하고 호스트 목록만 스크롤하도록 수정했습니다. OS 아이콘을 표시하며 검색창과 호스트 관리 버튼은 고정합니다.
- 제품 README를 소개·설치·사용법 중심으로 정리했습니다. 버전별 변경 사항·날짜·배포 상태는 별도 릴리즈 노트로 모으고 최신 공개 설치 파일 링크를 사용합니다.

같은 Mac에서 Passport를 완전히 종료한 뒤 새 DMG의 앱을 응용 프로그램 폴더에 대치하면 기존 설정과 탭·분할을 유지합니다. 연결은 다시 시작해야 합니다. 설치 파일은 ad-hoc 서명이며 Developer ID 서명·공증·앱 내부 자동 설치는 포함하지 않습니다.
