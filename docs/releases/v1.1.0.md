# Passport 1.1.0

로컬 AI 작업과 SSH 터미널을 같은 앱에서 사용합니다. 왼쪽 **+**로 로컬 터미널을 바로 열고, 자주 쓰는 탭 하나의 구성을 템플릿으로 저장하세요.

## 주요 변경

- 로컬·SSH 혼합 분할, 프로젝트 폴더와 설정, 실행 중인 패널의 탭·창 이동을 지원합니다. 열린 로컬 셸에서 설치된 `claude`·`codex`를 실행합니다.
- **설정 → 로컬 터미널**에서 셸과 여러 시작 프로파일, 적용 순서·환경 변수·PATH·단축 명령을 선택합니다. Mac은 기본 셸·zsh·bash, Windows는 내장 Passport Bash·cmd·Windows PowerShell·PowerShell 7을 지원합니다. Passport Bash는 외부 Git Bash 설치가 필요 없습니다.
- Claude의 응답 종료·승인 요청과 Codex의 응답 완료를 알림함에 모으고 조건에 따라 OS 알림을 요청합니다. 알림에서 해당 터미널로 이동할 수 있습니다. 도구별 연동 허용과 AI 작업 알림 프로파일을 설정한 후 새 터미널을 여세요.
- 템플릿을 **탭 하나와 내부 분할** 단위로 저장합니다. 탭 안의 상단 저장 아이콘을 누르고, 템플릿 화면의 카드를 눌러 같은 구성으로 새 탭을 엽니다. 실행 중인 프로세스와 AI 대화는 저장하지 않습니다.
- 여러 패널로 묶인 탭 전체를 다른 탭에 넣는 드래그를 차단합니다. 탭 순서 변경과 개별 패널 이동은 유지합니다. 중첩 분할의 빈 공간, 사이드바 여백과 시작 아이콘 표시를 수정했습니다. 새 로컬 탭의 입력 포커스도 화면 준비 후 적용합니다.
- CLI의 RGB·256색 출력, 로컬 PTY 종료와 재연결, 같은 데이터 폴더의 중복 실행을 개선했습니다. 종료 중 설정 파싱 오류와 첫 화면을 닫을 때 발생하던 불필요한 시작 실패 알림을 수정했습니다.
- Windows cmd에서 시작 프로파일을 실행하지 못하던 따옴표 처리와 DOSKEY 단축 명령 등록을 수정했습니다. 내장 Bash·cmd·Windows PowerShell·PowerShell 7의 환경 변수·PATH·단축 명령을 실제 패키지에서 검증했습니다.
- Windows 드라이브의 보호된 시스템 파일 하나를 읽지 못해 전체 파일 목록을 열지 못하던 문제를 수정했습니다.
- Windows에서 마지막 출력 뒤 조용한 로컬 터미널을 닫으면 앱 종료가 멈출 수 있던 문제를 수정했습니다.
- README 화면과 사용법, 셸·알림·템플릿·개발·배포 문서를 갱신했습니다.

## 업데이트와 데이터

기존 Passport를 완전히 종료하고 새 DMG 또는 EXE로 업데이트하세요. DB는 변경 전 `before-v5-<timestamp>.sqlite`를 백업한 뒤 스키마 5로 이행합니다. 문서·내보내기 형식은 버전 2입니다. 업데이트한 데이터는 이전 앱으로 열 수 없습니다.

**여러 탭을 한꺼번에 저장한 이전 템플릿은 제거합니다.** 단일 탭 템플릿·열린 작업 배치·호스트는 유지합니다. 이전 내보내기 파일을 가져올 때도 여러 탭 템플릿을 제외하고 미리보기에 개수를 표시합니다. 앱 재시작과 가져오기만으로 터미널을 자동 실행하지 않습니다.

## 제공 범위

**1.1.0 설치 파일은 Mac Apple Silicon용 DMG와 Windows x64용 EXE를 제공합니다.**

Mac Apple Silicon(macOS 14 이상)과 Windows 11 x64용입니다. Windows ARM64 설치·실행 검증은 완료하지 않았습니다. AI CLI 설치와 로그인은 별도로 필요합니다. 실제 OS 배너는 알림 허용·방해 금지·앱의 표시 조건에 따라 달라집니다.

Mac은 ad-hoc 서명으로 Developer ID·Apple 공증이 없고 Windows EXE도 코드 서명되지 않았습니다. Mac 업데이트 후 운영체제가 접근 권한을 다시 요청할 수 있습니다.
