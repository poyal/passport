## 설치

**현재 배포 버전은 1.0.0입니다.** Apple Silicon Mac용 설치 파일을 [GitHub Releases](https://github.com/poyal/passport/releases/tag/v1.0.0)에서 받으세요.

`main`의 수정본은 **1.0.1**입니다. 아래 화면과 사용 안내는 수정본을 기준으로 하며, 변경 내용은 [1.0.1 안내](docs/releases/v1.0.1.md)에 있습니다. 공개 다운로드는 위에 표시한 배포 버전을 확인하세요.

| 내 컴퓨터                     | 설치 파일                                                                                                               | 제공 상태 |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- | --------- |
| Mac · Apple Silicon(M 시리즈) | [Passport-1.0.0-mac-arm64.dmg](https://github.com/poyal/passport/releases/download/v1.0.0/Passport-1.0.0-mac-arm64.dmg) | 배포 중   |
| Windows · Intel / AMD(x64)    | `.exe` 설치 프로그램                                                                                                    | 준비 중   |
| Windows · ARM64               | ARM64용 `.exe` 설치 프로그램                                                                                            | 준비 중   |

### Mac에 설치하기

1. 위의 **DMG 설치 파일**을 다운로드하고 엽니다.
2. **Passport**를 **응용 프로그램(Applications)** 폴더로 옮깁니다.
3. 복사가 끝나면 Finder에서 Passport 설치 디스크를 추출합니다.
4. **응용 프로그램** 폴더에서 Passport를 실행합니다.

macOS 14 이상과 Apple Silicon(M 시리즈)을 대상으로 합니다. Rosetta는 필요하지 않으며 Intel Mac은 지원하지 않습니다. macOS 27의 로컬 환경과 macOS 15의 GitHub Actions에서 앱 실행을 확인했습니다.

### 처음 실행할 때

현재 Mac 배포는 ad-hoc 서명이며 Apple의 Developer ID 서명·공증을 포함하지 않습니다. 공식 Release에서 받은 앱을 처음 실행할 때 개발자 확인 안내로 실행이 차단되면 다음 순서로 허용합니다.

1. 응용 프로그램 폴더의 Passport를 한 번 실행하고 안내창을 닫습니다.
2. **시스템 설정 → 개인정보 보호 및 보안**에서 Passport의 **그래도 열기**를 누릅니다.
3. 확인창에서 **열기**를 선택하고, Mac 인증을 요청하면 진행합니다.

이후에는 응용 프로그램 폴더에서 바로 실행할 수 있습니다. [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445).

저장한 비밀번호를 사용할 때 **Passport Safe Storage** 키체인 창이 나타나면 Mac의 **로그인 키체인 암호**를 입력하세요. 보통 Mac 로그인 암호와 같습니다. 신뢰하는 설치본에 **항상 허용**을 선택하면 반복 요청을 줄일 수 있습니다. 자세한 내용은 [인증 정보 안내](docs/user-guide.md#호스트-등록과-연결)를 참고하세요.

### 기존 버전에서 업데이트하기

1. **Passport 종료(⌘Q)**로 앱을 완전히 종료합니다.
2. 새 DMG를 열고 Passport를 **응용 프로그램** 폴더로 복사합니다. 기존 앱을 교체할지 물으면 **대치**를 선택합니다.
3. 설치 디스크를 추출하고 응용 프로그램 폴더에서 새 버전을 실행합니다.

앱을 덮어쓰기만 해도 같은 Mac의 기존 호스트·인증·설정과 탭·분할 배치는 유지됩니다. 서버 연결은 직접 다시 시작합니다. 설정 내보내기는 업데이트의 필수 단계가 아니며, 중요한 데이터의 별도 백업을 원할 때 **설정 → 내보내기와 백업 → 내보내기**에서 저장할 수 있습니다. 업데이트 후 키체인 허용을 다시 요청할 수 있습니다.

**1.0.1부터 앱 시작 시 GitHub Releases의 새 버전을 자동 확인**합니다. **설정 → About → 업데이트 확인**에서도 확인할 수 있습니다. 업데이트가 있으면 하단의 새 버전 버튼으로 About을 열고 **설치 파일 다운로드**를 눌러 브라우저에서 받으세요. 이 기기에 맞는 설치 파일이 게시된 경우에만 다운로드 버튼이 표시됩니다. 설치와 앱 재시작은 위 순서대로 직접 진행합니다. 인터넷 연결 실패는 업데이트 확인에만 영향을 주며 터미널 작업은 계속할 수 있습니다. 기존 1.0.0에는 확인 기능이 없으므로 1.0.1은 한 번 직접 설치해야 합니다.

### 다운로드 파일 확인하기

DMG와 [SHA256SUMS.txt](https://github.com/poyal/passport/releases/download/v1.0.0/SHA256SUMS.txt)를 같은 폴더에 저장한 뒤 터미널에서 확인할 수 있습니다. 다운로드 폴더에 저장했다면 다음을 실행하세요.

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt
```

`Passport-1.0.0-mac-arm64.dmg: OK`가 표시되면 게시된 파일과 일치합니다.

Windows x64·ARM64 설치 파일은 준비 중이며 이번 릴리스에 포함하지 않습니다.

## 주요 기능

| 기능                 | 할 수 있는 일                                                               |
| -------------------- | --------------------------------------------------------------------------- |
| **호스트 관리**      | 그룹·태그·즐겨찾기, 일괄 편집, 자동 OS 아이콘과 수동 아이콘 선택            |
| **구형 SSH 호환**    | CentOS 5/6 등 구형 서버의 키 교환을 자동 지원하고 현대 알고리즘을 우선 선택 |
| **탭과 분할 터미널** | SSH 연결을 탭으로 열고 드래그로 분할, 크기 조절, 별도 창으로 이동           |
| **양쪽 파일 탐색**   | 로컬·SFTP·FTP·명시적 FTPS 연결, 드래그와 우클릭 메뉴로 파일 전송            |
| **명령어 스니펫**    | 자주 쓰는 명령을 저장하고 선택한 터미널 또는 현재 탭 전체에 전달            |
| **테마와 글꼴**      | 기본 테마 12종, 사용자 테마, 글꼴·커서, 로그·주소·파일 종류별 색상          |
| **내 작업 환경**     | 로컬 터미널, 포트 포워딩, 최대 30일 자동 로그 기록, 파일로 설정 내보내기    |

### 호스트를 정리하고 빠르게 연결

이름·주소·계정·태그로 검색하고, 그룹에 공통 설정을 지정하세요. 호스트를 두 번 클릭하면 연결됩니다.

아이콘을 선택하지 않으면 호스트 이름과 접속 후 OS 감지로 자동 표시합니다. 사용자가 직접 선택한 아이콘은 유지합니다.

![그룹과 태그로 정리한 Passport 호스트 목록](docs/assets/hosts.png)

### 서로 다른 서버도 같은 화면에서

좌우 패널에 각각 컴퓨터나 서버를 선택하세요. 우클릭으로 복사·이름 변경·새 폴더·권한 변경을 사용하고, 아래 전송 목록에서 결과를 확인할 수 있습니다.

![Passport 양쪽 SFTP 파일 목록과 우클릭 메뉴](docs/assets/files.png)

### 오래 보는 터미널을 내 취향대로

앱의 라이트·다크 모드와 터미널 테마를 따로 선택할 수 있습니다. 글꼴과 크기를 바꾸고 로그·주소 강조로 필요한 출력을 찾아보세요.

**파일·폴더 색상 구분**은 기본으로 켜집니다. 색상이 없는 `ls -l`·`ll` 출력에서도 폴더·실행 파일·심볼릭 링크 이름을 각 테마에 맞춰 표시합니다. 서버가 보낸 ANSI 색상과 복사할 원문은 유지합니다.

![Passport 터미널 외형 패널과 테마 목록](docs/assets/appearance.png)

### 창 크기에 맞는 설정 화면

외형은 앱·터미널·테마로 나누고 기본·사용자 테마를 한 탭에서 관리합니다. 인증 프로필, 내보내기·가져오기·백업, 세션 로그도 탭으로 정리했습니다. 창 너비에 맞춰 카드와 입력란이 배치됩니다. 터미널 옵션은 ON/OFF 스위치로 조절합니다.

![Passport 1.0.1 설정의 외형 탭과 터미널 테마](docs/assets/settings.png)

## 시작하기

1. **호스트 → 새 호스트**에서 서버 주소·포트·사용자 이름을 저장합니다.
2. 호스트를 두 번 클릭하고 비밀번호나 SSH 개인 키로 연결합니다. 처음 연결하는 서버는 관리자가 제공한 SSH 지문과 비교한 뒤 승인합니다.
3. 탭을 다른 탭 위에 잠시 올린 뒤 터미널 가장자리로 드래그하면 분할됩니다. 분할 경계를 끌어 크기를 조절하세요.
4. **파일**에서 좌우 연결을 선택하고 파일을 반대편으로 드래그하거나 우클릭 메뉴로 복사합니다.

명령어 저장, 여러 창에 붙여넣기, 로그와 포트 포워딩은 [사용 안내](docs/user-guide.md)에서 확인하세요.

첫 지문 확인창은 **설정 → 인증 프로필 → SSH 호스트 키**에서 생략할 수 있습니다. 이미 등록된 지문이 바뀌면 연결을 차단합니다. 지문 교체·신규 자산 선택 화면은 아직 제공하지 않습니다.

## 내 설정을 다른 컴퓨터로

**설정 → 내보내기와 백업**에서 호스트·그룹·스니펫·작업 배치·설정을 파일로 내보내고 다른 컴퓨터에서 가져올 수 있습니다. 비밀번호와 개인 키는 기본적으로 제외하며, 포함할 때는 별도의 암호로 보호합니다.

작업 배치는 자동 저장되며 앱을 다시 열면 탭과 분할을 복원합니다. 서버 연결은 직접 재연결합니다.

## 개발과 검증

소스에서 실행하거나 빌드하려면 [개발 안내](docs/development.md)를 확인하세요. 수정본 1.0.1은 단위·통합 82개, GUI 시나리오 27개와 패키지 실행 검증을 통과했습니다. 1.0.0에서 수행한 누적 1GiB 터미널 출력 시험을 포함해 자세한 결과는 [검증 기록](docs/verification.md)에 있습니다. 출력 시험은 최근 10,000행 스크롤백을 사용하며 최대 지원량을 뜻하지 않습니다.
