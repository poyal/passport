# Passport 사용 안내

[제품 소개와 설치](../README.md) · [전체 문서](README.md)

Passport는 한국어로 사용하는 개인용 SSH·파일 전송 앱입니다. 서버 정보와 작업 환경은 내 컴퓨터에 저장하며, 다른 컴퓨터로 옮길 때는 파일 내보내기와 가져오기를 사용합니다.

## 호스트 등록과 연결

1. **호스트 → 새 호스트**를 누릅니다.
2. 빈 입력칸에 이름, 서버 주소와 사용자 이름을 입력합니다. 포트를 비워 두면 SSH/SFTP는 22, FTP/FTPS는 21을 사용합니다.
3. SSH 호스트를 두 번 클릭하거나 **SSH 연결**을 누릅니다.
4. 저장된 인증이 없으면 연결할 때 비밀번호 또는 SSH 개인 키를 입력합니다. 처음 연결하는 서버는 관리자가 제공한 SSH 지문과 비교한 뒤 승인합니다.

호스트에 비밀번호를 함께 입력하면 저장 시 암호화된 인증 프로필을 만듭니다. 비워 두면 연결할 때 입력합니다.

**설정 → 인증 프로필**에 인증 정보를 등록하면 여러 호스트에서 재사용할 수 있습니다. 프로필에 사용자 이름을 지정하면 호스트에서는 해당 계정을 자동으로 사용하며 ID·비밀번호 입력칸 대신 인증 카드가 나타납니다. 카드를 누르면 이름·계정으로 저장된 인증을 검색하거나 직접 입력으로 전환할 수 있습니다. 사용자 이름을 비워 둔 공통 인증 프로필은 호스트별 계정과 함께 사용할 수 있습니다. 비밀번호나 개인 키를 저장·사용할 때 macOS 키체인이 접근 허용을 요청할 수 있습니다.

그룹·태그·즐겨찾기로 호스트를 정리하고 이름·주소·계정·태그로 검색할 수 있습니다. **설정 → 그룹 관리 → 그룹 기본값**에서 공통 설정을 정하고, 호스트 설정의 **상속 · 시작 명령 · 키 설정**에서 상속할 항목을 선택하세요. 여러 호스트를 체크한 뒤 **일괄 편집**을 열면 체크한 설정만 변경합니다.

아이콘은 선택하지 않으면 호스트 이름에서 OS를 추정하고, SSH/SFTP 연결 후 실제 감지 결과를 우선 표시합니다. 추정값은 툴팁에 ‘이름에서 추정’으로 표시합니다. Alpine·CentOS·Red Hat·Rocky·Ubuntu·Debian·Fedora·Linux·macOS·Windows를 색상과 로고로 구분합니다. 직접 지정한 아이콘은 Linux를 포함해 감지 결과보다 우선하며, 호스트의 **아이콘 → 자동**으로 바꿀 수 있습니다. 예전 가져오기에서 일괄 지정한 Linux 아이콘은 자동 모드로 읽습니다. 이후 직접 선택한 Linux 아이콘은 유지합니다. 그룹 추가·변경·삭제는 **설정 → 그룹 관리**에 있습니다.

0.3.3부터 CentOS 5/6 등 구형 서버 호환은 모든 SSH·SFTP·터널 연결에 자동으로 적용합니다. 별도의 **SSH 알고리즘** 옵션은 없습니다. 현대 키 교환을 먼저 선택하며, 서버가 구형 방식만 제공하면 SHA-1 group14·GEX·group1도 사용할 수 있습니다. 이전 버전에서 호환 옵션을 꺼 둔 호스트에도 적용합니다. 약한 알고리즘을 허용하므로 구형 서버 연결의 보안 수준은 현대 방식보다 낮습니다. 그래도 `no matching key exchange algorithm` 오류가 나면 서버의 SSH 설정을 확인하거나 업데이트하세요.

처음 연결할 때 지문 확인창을 생략하려면 **설정 → 인증 프로필 → SSH 호스트 키 → 첫 연결 지문 확인창 표시**를 끄세요. 처음 받은 지문을 자동 등록하므로 첫 연결 대상이 올바른 서버인지 직접 확인해야 합니다. 이후 등록된 지문이 바뀌면 연결은 차단됩니다.

macOS의 **Passport Safe Storage** 접근 요청은 저장한 인증 정보를 보호하는 키체인 창입니다. 서버 비밀번호 대신 Mac의 **로그인 키체인 암호**를 입력하세요. 보통 Mac 로그인 암호와 같습니다. 신뢰하는 Passport 설치본에 **항상 허용**을 선택하면 이후 접근 요청을 줄일 수 있습니다. 현재 Mac 설치본은 ad-hoc 서명이라 업데이트 후 다시 요청할 수 있습니다. Safe Storage 키를 삭제하면 기존 인증 정보를 복호화하지 못할 수 있습니다.

## 탭과 분할 터미널

- 호스트를 연결하면 작업 탭이 열립니다. **터미널 분할** 버튼으로 다른 호스트를 같은 탭에 추가할 수 있습니다.
- 탭을 다른 탭 위에 잠시 올려 해당 화면으로 전환한 뒤, 터미널의 상하좌우 가장자리에 놓으면 합쳐집니다. 패널 제목도 드래그할 수 있습니다.
- 분할 경계를 드래그해 크기를 조절합니다. **집중 보기**로 한 패널을 크게 보고 **분할 복원**으로 돌아갑니다.
- **패널 위치 이동**은 키보드로도 사용할 수 있습니다. **새 탭으로 분리**로 분할한 패널을 다시 탭으로 꺼낼 수 있습니다.
- **운영 도구**에서 작업 탭을 새 창이나 다른 Passport 창으로 옮깁니다. 이동할 때 연결과 이전 출력은 유지됩니다.

분할과 파일 연결은 검색 창에서 이름·주소·계정·태그 또는 그룹으로 호스트를 찾아 선택합니다.

한 작업 탭에는 최대 16개, 전체에는 최대 32개 터미널을 열 수 있습니다. 작업 배치는 자동 저장되며 앱을 다시 열면 직접 연결합니다.

**새 SSH 탭 → 로컬 터미널 열기**로 내 컴퓨터의 셸도 사용할 수 있습니다. 설치된 셸과 시작 경로를 선택하세요.

## 파일 전송과 우클릭 메뉴

**파일** 화면에서 좌우 패널의 연결을 각각 선택합니다. 내 컴퓨터와 서버, 또는 서로 다른 서버를 나란히 열 수 있습니다. SFTP·FTP·명시적 FTPS를 사용할 수 있습니다.

목록 맨 위의 **..** 행을 한 번 클릭하면 상위 폴더로 이동합니다.

파일이나 폴더를 선택하고 반대편으로 드래그하거나 **왼쪽 → 오른쪽 / 왼쪽 ← 오른쪽** 버튼으로 복사하세요. 같은 이름의 파일은 상단에서 **건너뛰기 / 덮어쓰기 / 이름 변경** 중 하나로 처리합니다.

우클릭 메뉴에는 반대편 폴더로 복사, 이름 변경, 새로고침, 새 폴더, 빈 파일 만들기, 삭제가 있습니다. SFTP에서는 **권한 변경**도 사용할 수 있습니다. 파일 내용의 원격 편집 기능은 제공하지 않습니다.

전송 목록에서 진행 상황·완료·실패를 확인하고 취소하거나 재시도할 수 있습니다. 동시에 최대 3개 전송을 처리합니다. 재시도는 처음부터 전송하며, 앱을 닫으면 진행 중인 전송도 중단됩니다. 연결이 끊겼다면 같은 패널에서 같은 호스트에 다시 연결한 후 재시도하세요. 삭제한 파일은 휴지통으로 이동하지 않습니다.

## 스니펫과 여러 터미널에 입력

1. 작업 탭에서 **스니펫 → 새 스니펫**을 선택합니다.
2. 이름과 명령어를 입력합니다. `{{name}}`처럼 변수를 넣으면 사용할 때 값을 입력할 수 있습니다.
3. 선택한 터미널 또는 **현재 탭 전체**를 대상으로 지정하고 붙여넣습니다. 실행하려면 별도의 **명령 실행** 미리보기에서 확인합니다.

클립보드와 **붙여넣기**는 확인 창 없이 바로 전달하며 Enter를 추가하지 않습니다. 클립보드의 `{{문자}}`는 변수로 해석하지 않습니다. **명령 실행**은 Enter까지 보내므로 실행할 대상과 명령을 먼저 확인하세요. 변수는 입력한 문자로 치환됩니다.

**운영 도구**의 동시 입력을 켜면 현재 작업 탭에서 지정한 SSH 터미널에 같은 키 입력을 전달합니다. 탭 전환·도구 닫기·창 이동 시 해제됩니다. 명령 제안은 앱에서 실행한 이력과 저장한 스니펫을 사용합니다.

호스트 설정에서 시작 스니펫을 선택할 수 있습니다. 시작 스니펫은 변수가 없는 명령만 사용하며, 연결이 끊겼다가 자동 재접속할 때는 다시 실행하지 않습니다.

## 테마·글꼴·단축키

**설정 → 외형**은 **앱 외형·터미널 설정·테마·사용자 테마** 탭으로 나뉩니다. 앱의 라이트·다크 모드와 전체 터미널 기본 외형을 각각 정합니다. 모든 설정 카드는 창 너비에 맞춰 늘어나고 입력란·목록은 가용 너비에 맞춰 배치합니다. 작업 탭의 **외형**에서는 현재 세션 외형을 조절할 수 있습니다.

- 기본 테마 12종과 사용자 테마.
- 글꼴, 크기, 굵기, 줄 간격, 자간, 커서 모양과 깜박임.
- 기본·로그·행·주소 출력 강조.

**파일·폴더 색상 구분**은 기본으로 켜집니다. 색상이 없는 `ls -l`·`ll` 출력에서 권한 표기를 읽어 이름만 구분합니다. 폴더는 테마의 블루·퍼플, 실행 가능한 파일은 그린, 심볼릭 링크는 시안으로 표시합니다. 라이트·다크·사용자 테마 모두 같은 팔레트 규칙을 따릅니다. 서버가 이미 보낸 ANSI 색상은 유지하며 일반 파일·입력·복사할 원문과 서버 설정을 바꾸지 않습니다. 권한 정보가 없는 단순 파일 이름 목록은 임의로 분류하지 않습니다.

외형은 전체 기본값에 그룹, 호스트, 세션 설정을 차례로 적용합니다. 서버가 출력한 ANSI 색상을 우선하므로 `ls`의 파일 종류별 색상은 서버 설정에도 영향을 받습니다.

**설정 → 단축키**에서 복사·붙여넣기·검색·패널 전환·새 탭 키 조합을 바꿀 수 있습니다.

## 포트 포워딩과 세션 로그

**설정 → 포트 포워딩**에서 SSH 호스트와 로컬·원격·동적 SOCKS5 규칙을 저장한 뒤 직접 시작합니다. 기본 연결 대기 주소는 `127.0.0.1`입니다. 앱을 다시 실행해도 터널은 자동으로 시작하지 않습니다.

SSH와 로컬 터미널에 접속하면 기본적으로 출력을 자동 기록합니다. **설정 → 세션 로그 → 기록·보관 설정**에서 자동 기록, 보관 기간(1~30일), 전체 용량(10~1024MiB)을 조절하고 **로그 조회** 탭에서 검색·북마크·내보내기를 사용하세요. 기본은 30일·전체 1GiB이며 먼저 한도에 도달한 오래된 기록부터 지웁니다. 작업 탭의 **운영 도구**에서는 현재 세션 기록을 잠시 중지하거나 재개할 수 있습니다. 로그에는 터미널에 출력된 내용이 저장됩니다.

## 설정 내보내기·가져오기와 백업

1. **설정 → 내보내기와 백업**의 **내보내기** 탭을 엽니다. 호스트·그룹·스니펫·작업 배치·설정을 함께 저장합니다.
2. 비밀번호·개인 키는 기본적으로 제외됩니다. 포함하려면 체크한 뒤 10자 이상의 별도 암호를 지정합니다.
3. **내보내기**를 누르고 파일을 저장합니다.
4. 다른 컴퓨터에서 파일을 가져오고 미리보기를 확인한 뒤 적용합니다.

내보내기 파일에는 실행 중인 연결·터널, 세션 로그 파일, 명령 이력이 포함되지 않습니다. 다른 컴퓨터에서는 로컬 시작 경로를 다시 지정하고 사용할 글꼴과 셸도 확인하세요.

**가져오기** 탭에서 설정 파일을 선택하고 **자동 백업** 탭에서 최근 일별 백업을 확인합니다. 하위 탭을 바꿔도 입력 중인 내보내기 암호·가져오기 옵션은 유지됩니다. 기기 간 이동에는 내보내기 파일을 사용하세요. 자동 동기화와 자동 업데이트는 제공하지 않습니다. 새 버전 설치 전 설정을 내보내 두는 것을 권장합니다.

## 연결이나 표시가 이상할 때

| 증상                             | 확인할 내용                                                        |
| -------------------------------- | ------------------------------------------------------------------ |
| 서버에 연결되지 않음             | 주소·포트·계정, 네트워크와 서버의 SSH 또는 파일 서비스 실행 상태   |
| 인증 실패                        | 호스트에 선택된 인증 프로필, 비밀번호·개인 키·키 암호              |
| SSH 지문이 변경됐다는 안내       | 서버를 재설치했거나 접속 대상이 바뀌었는지 서버 관리자에게 확인    |
| 파일 전송 실패                   | 대상 경로의 쓰기 권한과 남은 공간. 재연결 후 전송 목록에서 재시도  |
| 다른 기기에서 글꼴·경로가 달라짐 | 해당 기기에 글꼴·셸이 설치되어 있는지, 로컬 경로가 존재하는지 확인 |

문제를 전달할 때 Passport 버전, 운영체제와 칩 종류, 재현 순서, 오류 문구를 함께 남겨 주세요. 비밀번호·개인 키와 개인 서버 주소는 화면에서 가려 주세요.
