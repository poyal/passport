# Passport 1.0.1 수정 안내

`main`의 수정본입니다. 공개 GitHub Release는 아직 1.0.0이며, 설치 파일 게시 여부는 [Releases](https://github.com/poyal/passport/releases)에서 확인하세요.

- 인증 정보를 포함해 내보낼 때 10자 이상의 암호 조건, 현재 글자 수와 내보내기 가능 여부를 표시합니다.
- 가져올 파일을 먼저 선택하고 암호화된 파일에만 암호 입력창을 표시합니다. 틀린 암호는 같은 창에서 다시 입력할 수 있습니다.
- 세션 로그 조회·검색에서 ANSI 색상, 커서 이동과 하이퍼링크 제어 코드를 숨깁니다. 로그 원본과 내보내기는 유지합니다.
- 터미널 설정의 커서 깜박임·주소 강조·파일 색상 옵션을 ON/OFF 스위치로 바꿉니다.
- 기본 테마와 사용자 테마 관리를 같은 탭에 모읍니다.
- 작업 탭 도구를 아이콘 버튼으로 정리하고 기능 이름 툴팁을 제공합니다.
- 터미널 검색에 결과 수, 이전·다음 이동, Enter·Shift+Enter·Esc와 더 선명한 강조를 추가합니다. 검색창을 열어도 터미널 크기가 바뀌지 않습니다.
- About에 제작자 Poyal, poyal.work@gmail.com, GitHub·이슈·릴리즈 링크와 설치 버전을 표시합니다.

같은 Mac에서 앱을 종료하고 새 DMG의 Passport를 응용 프로그램 폴더에 대치하면 기존 설정과 작업 배치를 유지합니다. 연결은 다시 시작해야 합니다. 별도 백업은 선택 사항입니다.

로그 조회는 터미널 화면을 재현하지 않으므로 TUI 프로그램의 반복 출력이 남을 수 있습니다. 검색 결과 강조·집계는 최대 1,000개이고 이후는 `1000+`로 표시합니다.
