# Passport 1.3.3 AI 기록

이 문서는 1.3.3의 배포 소스·검증 환경·최종 결과·남은 제한을 기록합니다. 공통 작업 지침은 [루트 AGENTS](../../../AGENTS.md), 개발·E2E·문서 규칙은 [공통 개발 규칙](../../development.md), 검증·게시·정리 절차는 [릴리즈 가이드](../../release.md)를 따릅니다. 사용자 조작은 [1.3.3 매뉴얼](README.md)에서 확인합니다.

## 버전별 데이터와 화면 기준

SQLite 스키마는 5, 문서·portable 형식은 2입니다. 매뉴얼 전체 화면은 1.3.1 최종 Mac 앱에서, 앱 내부 쪽지 가이드의 두 부분 화면은 1.3.1 Windows UI에서 격리된 예제 데이터로 촬영했습니다. 변경되지 않은 화면을 재사용하며 1.3.3에서 새로 촬영한 화면으로 표시하지 않습니다.

## 검증과 공개 상태

Mac ARM64 1.3.3 배포 후보이며 **아직 미배포**입니다. 사용자 요청에 따라 이 컴퓨터에서는 소스·문서 푸시까지만 완료하고, 정식 검증·태그 생성·GitHub 게시를 다른 컴퓨터에서 이어갑니다. 이번 작업에서는 v1.3.3 태그나 GitHub Release를 생성하지 않았으며 사용자 설치본도 교체하지 않았습니다.

Windows 공개판은 [v1.3.1](https://github.com/poyal/passport/releases/tag/v1.3.1)이며 1.3.3 네이티브 검증·게시 대상에는 포함하지 않습니다. 추후 Windows 1.3.3을 추가하려면 공개된 v1.3.3 태그와 동일한 소스를 사용해야 합니다.

최초 종료 지연은 앱의 자체 정리 완료 뒤 발생했으며 원인은 미확정입니다. 후속 진단의 정상 종료를 최초 원인 해결로 간주하지 않습니다. DMG 재검사에서 실패한 OpenSSH 붙여넣기 사례는 Electron 텍스트 모의 처리와 달리 AppKit 파일 읽기가 사용자 클립보드에 접근하던 시험 격리 누락입니다. `d8db4bb18273d994d8a36a44da35a1ae2e1cad11`에서 시험용 named pasteboard로 분리하고 공통 검사 규칙을 보완했습니다. 앱 코드는 바꾸지 않았습니다.

수정 후 전체 정식 검증·실제 데스크톱 검사는 아직 수행하지 않았습니다. 시험용 DMG·보고서·로그·임시 도구는 이 컴퓨터의 작업 종료 시 정리하며, 재개할 Mac에서는 최신 main을 가져온 뒤 [릴리즈 가이드](../../release.md)에 따라 깨끗한 후보 커밋에서 전체 정식 검증을 새로 수행해야 합니다. 통과한 동일 커밋과 설치 파일로 태그·게시·공개 다운로드 확인을 진행하고, README의 미배포 표시와 이 문서의 소스·결과·해시를 확정합니다.

## 확인 범위와 남은 제한

- [이슈 #8](https://github.com/poyal/passport/issues/8)의 국기·분해형 한글·ZWJ 재현은 터미널별 macOS zsh 호환 모드로 대응합니다. 기본값은 Unicode 11이며 모든 셸·TUI·복합 문자의 폭이 동일함을 보장하지 않습니다.
- [이슈 #9](https://github.com/poyal/passport/issues/9)의 친구 요청 수신자 CLI 송수신, 앱을 유지한 터미널 재연결과 프로파일 적용을 회귀 검사합니다. Codex 모의 실행으로 인수 전달·환경 상속을 확인하는 범위이며, 실제 Codex `resume` 내부 동작이나 최초 장애 원인을 확정한 것은 아닙니다.
- 쪽지 조회·승인·읽기의 사용자 허락은 AI 안내문에서 대화상 범위를 요구합니다. 앱이 대화상 허락을 독립적으로 검증하지는 않습니다. 친구 등록 승인은 앱에서만 처리합니다.
- 두 앱의 루프백·safeStorage 모의 검사는 실제 다른 PC의 LAN·Keychain 실기와 구분합니다. 이전 버전의 실기 결과를 이 버전의 결과로 간주하지 않습니다.
- Windows 실기·물리 IME·실제 AI 서비스·OS 알림·깨끗한 계정의 설치/업그레이드·macOS 14 실기·Developer ID/Apple 공증은 별도 확인 대상입니다.
