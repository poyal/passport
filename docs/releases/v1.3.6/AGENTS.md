# Passport 1.3.6 검증 기록

## 범위와 소스

Mac ARM64만 게시하는 1.3.6 후보입니다. Windows 1.3.6은 검증·게시 대상이 아니며 공개 Windows 설치본은 1.3.5를 유지합니다. 정식 소스는 검증을 통과한 `v1.3.6` 태그 커밋으로 확정합니다.

일반 텍스트 HTTP/HTTPS 주소를 기존 링크 확인·브라우저 열기 경로에 연결합니다. 표·괄호 안의 주소, 자동 줄바꿈된 주소와 명시적 하이퍼링크의 실제 목적지를 함께 검사합니다. 이전 Mac 1.3.5 이후 반영된 좁은 세션 로그 화면의 읽기 영역 보장과 화면 재로드 후 빈 터미널이 저장된 이력을 덮어쓰지 않도록 한 수정도 포함합니다.

## 검증·공개 상태

현재 후보의 정식 검증·DMG 게시·공개 다운로드 확인은 미실행입니다. 이전 개발 앱과 다른 버전의 검사 결과를 이 후보의 성공으로 사용하지 않습니다. 사용자는 이번 Mac 릴리즈의 실제 데스크톱 검사를 허용했습니다.

Mac 앱은 기존 ad-hoc 서명을 사용하며 Developer ID·Apple 공증은 포함하지 않습니다. Windows 실기·설치 파일, 물리 IME, 다른 PC와의 LAN, 실제 AI 서비스, 깨끗한 계정의 설치·제거·업그레이드와 선택 검사는 별도 범위입니다.

사용자 매뉴얼은 [1.3.6 README](README.md), 공통 절차는 [개발 가이드](../../development.md)와 [릴리즈 가이드](../../release.md)를 따릅니다. 매뉴얼 화면은 기존 1.3.5·1.3.1 촬영본을 재사용합니다.
