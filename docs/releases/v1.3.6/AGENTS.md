# Passport 1.3.6 검증 기록

## 범위와 공개 소스

2026-10-21 [v1.3.6](https://github.com/poyal/passport/releases/tag/v1.3.6)의 **Mac ARM64·Windows x64** 설치본을 공개했습니다. 배포 소스는 `v1.3.6` 태그의 `d0e169ce926887e702902bc3309a0a344039da01`입니다. 후속 문서 커밋은 바이너리 소스와 구분합니다. Windows 추가 배포도 같은 `v1.3.6` 소스를 사용했으며 정식 검증과 공개 다운로드 확인을 완료했습니다.

SQLite 스키마 7, 문서·portable 형식 2를 유지합니다. 일반 텍스트 HTTP/HTTPS 주소는 기존 소유 창 검사·실제 주소 확인·브라우저 열기 경로를 사용합니다. 표·괄호 안의 주소, 자동 줄바꿈된 주소와 명시적 하이퍼링크의 실제 목적지를 소스와 최종 설치본에서 검사했습니다. 새 PTY는 부모 Passport 세션의 인증·AI 실행·복원·시작 로더 상태를 제거하고 자신의 세션 값을 설정합니다.

사용자 매뉴얼은 [1.3.6 README](README.md), 공통 절차는 [개발 가이드](../../development.md)와 [릴리즈 가이드](../../release.md)를 따릅니다. 매뉴얼의 기존 1.3.5·1.3.1 화면 이미지는 촬영 버전 표시를 유지해 재사용했습니다.

## Mac 검증 중 확인한 조건

- 첫 후보 `86bc634`는 기존 터미널의 복원 적용 검사에서 실패했습니다. 부모 Passport의 `PASSPORT_RESUME` 등 세션 환경이 새 PTY에 상속되는 원인을 수정했고, 부모 환경을 명시한 회귀 검사를 추가했습니다.
- `fc556d3`의 첫 정식 실행은 데스크톱 전경 알림 억제에서 실패했습니다. 같은 소스의 단독 사례·전체 데스크톱 진단은 통과했으며 외부 포커스 변경 여부 등 정확한 원인은 확정하지 못했습니다. 최종 소스·설치본 데스크톱 검사에서는 통과했습니다.
- 다음 `fc556d3` 실행은 설치본의 마지막 일반 셸 재연결에서 CLI 응답 대기가 실패했습니다. 같은 설치본의 단독 반복 진단 10회는 통과했습니다. 프로파일 없는 셸의 ready 상태가 첫 프롬프트를 보장하지 않는 시험의 대기 조건을 확인해, 각 세션 세대의 고유한 실제 프롬프트가 나온 뒤 명령을 보내도록 보완했습니다. 최종 소스·설치본에서 기존 인증·프로파일·재연결 검사를 모두 유지해 통과했습니다.
- `268868e`의 두 정식 실행은 새 DMG 앱의 실제 safeStorage가 키체인 승인을 기다리며 시간 초과됐습니다. 해당 프로세스의 `SecItemCopyMatching`·Security 호출 스택으로 확인했습니다. 사용자가 macOS 창에서 승인한 뒤 동일 DMG의 암호화·완전 재시작 진단을 통과했습니다. 새 후보마다 다시 승인할 시간을 확보하기 위해 설치 파일 단계에 최대 180초의 실제 키체인 암호화·복호화 준비를 추가했고, 최종 전체 정식 검증을 완료했습니다. 준비 실패는 릴리즈 실패로 처리하며 GUI와 정상 종료 제한 시간은 유지했습니다. 키체인 초기화·접근 제어 변경·평문 mock으로 우회하지 않았습니다.

`8ed40e0`의 정식 실행은 소스 전체와 DMG 내부 숨김 GUI 97개까지 통과했지만 설치본 전경 알림 검사에서 실패했습니다. 전체 데스크톱 순서의 별도 진단에서 CLI 실행 직후 네이티브 blur와 알림 시점의 전경 창 부재를 기록해 재현했습니다. 고정 대기만으로는 재발해 채택하지 않았습니다. 모의 CLI가 준비 신호를 보낸 뒤 실제 네이티브·renderer 포커스를 확인하고 알림을 방출하도록 동기화했습니다. 알림 발생 중 강제 포커스·네이티브 포커스 mock·시험 생략은 추가하지 않았습니다. 동일 설치본의 전체 순서 3회(12개) 진단과 최종 소스·설치본 데스크톱 검사가 통과했습니다.

앞선 실패 실행과 부분 진단은 최종 정식 결과를 대신하지 않았습니다. 게시에는 위의 단일 최종 실행에서 검증한 바이트만 사용했습니다.
