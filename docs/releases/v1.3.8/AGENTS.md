# Passport 1.3.8 검증 기록

Mac ARM64·Windows x64의 1.3.8 릴리즈 후보입니다. 초기 정식 검증의 시험 문제를 수정했으며 최종 정식 검증과 GitHub 공개는 아직 완료하지 않았습니다. 두 OS에서 같은 후보 커밋을 검증한 뒤 실제 결과와 설치 파일 해시를 이 문서에 확정합니다.

사용법은 [1.3.8 사용자 매뉴얼](README.md), 절차는 [릴리즈 가이드](../../release.md)를 따릅니다. UTF-8 기준 4 MiB 터미널 붙여넣기, 로컬 PTY·SSH 입력 순서 보존, 전송 진행 표시·용량 제한·Ctrl+C 취소를 포함합니다.

## 검증 상태

| 대상 | 정식 검증 | 공개 다운로드 |
| --- | --- | --- |
| Mac ARM64 | 수정 후보 검증 대기 | 미게시 |
| Windows x64 | 수정 후보 검증 대기 | 미게시 |

이번 사용자는 두 OS의 실제 데스크톱 검사를 명시적으로 허용했습니다. 소스 앱과 최종 설치 파일 내부 앱의 숨김 GUI·실제 데스크톱 검사를 모두 수행합니다. 이전 버전의 검사 수·해시를 이번 후보의 결과로 사용하지 않습니다.

## 초기 실패와 관련 검사

초기 후보 `9e47756f4985184165c8eb24ee8dbdb87d14ee5e`의 Mac 정식 실행은 단위·통합 295개와 배포 정책 85개 통과 후 AI 세션 복원 시험에서 실패했습니다. 두 프로세스의 복원 완료 순서를 배열 순서로 가정하던 시험을 패널 ID로 대응시키고 각 대화 ID·옵션을 확인하도록 수정했습니다. 수정 후 Mac 세션 복원 GUI 3개가 통과했습니다.

초기 Windows 실행은 단위·통합 291개 통과·10개 생략 후 4 MiB 직접 PTY 시험의 10초 수신 제한에서 실패했습니다. 실제 Windows Node 콘솔의 전체 Unicode 수신에 약 29초가 걸리며 최종 바이트 수·SHA-256은 일치함을 진단했습니다. 해당 단위 시험만 45초, 수신 대기를 35초로 설정하고 GUI의 해당 수신 대기도 35초로 맞췄습니다. GUI 전역 45초·정상 종료 10초 제한과 다른 검사는 유지했습니다. 이후 Windows 관련 단위 검사 13개와 대용량 붙여넣기·세션 복원 GUI 5개가 통과했습니다. 두 OS의 관련 GUI는 숨김 표시·네이티브 포커스 0, 모든 앱의 정상 종료·종료 감사 일치를 확인했습니다.

## 검증 범위와 제한

최소 지원 macOS 14 실기, 물리 IME, 실제 OS 알림, 다른 PC와의 LAN, 실제 유료 AI 서비스·설치된 AI CLI 선택 검사, 깨끗한 계정의 설치·제거·업그레이드, Docker·장시간 부하는 별도 범위입니다. Mac은 ad-hoc 서명이며 Developer ID·Apple 공증을 포함하지 않습니다. Windows EXE에는 Authenticode 서명이 없습니다. 사용자 설치 앱·실제 DB는 교체하지 않습니다.
