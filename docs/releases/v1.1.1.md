# Passport 1.1.1

파일·폴더의 전체 경로와 이미지를 터미널에 붙여넣고, 여러 창에서 AI 작업을 이어갈 수 있습니다. 배포 대상은 **macOS Apple Silicon(macOS 14 이상)**과 **Windows x64**입니다.

## 주요 변경

- **Windows 작업표시줄 아이콘 수정:** 실행 중인 창에 Electron 기본 아이콘이 표시되는 문제를 수정했습니다. Windows용 여러 크기의 ICO를 창과 실행 파일에 함께 적용합니다. 1.1.1을 이미 설치했다면 아래 EXE를 다시 받아 설치하세요. 같은 버전이므로 앱의 새 버전 알림은 나오지 않습니다.

- **파일·폴더·앱의 전체 경로 붙여넣기:** Finder에서 복사한 항목이 이름만 입력되던 문제를 수정했습니다. 한글·공백·작은따옴표가 있는 경로와 여러 파일을 셸에 맞게 입력하며 Enter를 자동으로 누르지 않습니다.
- **이미지 붙여넣기:** 클립보드의 이미지 픽셀을 PNG로 저장하고 로컬 터미널에 경로를 입력합니다. 연속 붙여넣기 순서와 원래 터미널을 유지하고 연결이 바뀌면 취소합니다. SSH에는 파일 전송을 통한 업로드를 안내합니다. Mac Ctrl+V와 Windows Alt+V는 CLI 자체 동작에 전달합니다.
- **터미널별 알림 읽음:** 활성 창에서 해당 터미널을 확인하면 그 터미널의 미읽음 표시를 지웁니다. 다른 터미널의 알림, 알림 기록과 승인 대기 상태는 유지합니다.
- **새 창 단축키:** ⌘N / Ctrl+N으로 현재 창에 로컬 터미널을, ⌘⇧N / Ctrl+Shift+N으로 새 Passport 창과 로컬 터미널을 엽니다. 기존 연결과 사용자 지정 단축키를 보존합니다.
- **글꼴 선택 확장:** 설치 글꼴 검색과 한글·표 미리보기를 추가했습니다. 내장 글꼴 7종(JetBrains Mono, Cascadia Mono/Code, Fira Code, Source Code Pro, IBM Plex Mono, D2Coding)을 오프라인으로 사용할 수 있습니다.
- **로컬 검증 후 배포:** 소스와 설치 파일을 로컬에서 검사한 뒤 검증한 바이트 그대로 게시합니다. 일반 E2E는 숨김 창으로 실행하고 실제 포커스 검사는 별도로 분리했습니다. 원격 Actions는 수동 진단용으로 유지합니다.
- **Windows Bash 입력 보정:** 터미널을 분할하거나 크기를 변경한 뒤 첫 입력 글자가 사라지던 문제를 수정했습니다. Bash 프롬프트에서만 보정하며 실행 중인 CLI의 입력은 유지합니다.
- **Windows 터미널 종료 안정성:** 여러 로컬 터미널을 닫고 다시 열 때 네이티브 PTY 핸들을 동시에 정리하면서 발생하던 충돌을 수정했습니다.

## 업데이트

Passport를 **⌘Q로 완전히 종료**한 뒤 새 DMG의 앱을 **응용 프로그램** 폴더로 옮겨 대치하세요. 설치 디스크를 추출한 뒤 실행합니다. 호스트·설정·작업 배치는 유지되며 서버 연결은 직접 다시 시작합니다.

설치 파일 `Passport-1.1.1-mac-arm64.dmg`와 같은 릴리즈의 `SHA256SUMS.txt`로 다운로드를 확인할 수 있습니다. Mac 설치본은 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다.

Windows에서는 Passport를 완전히 종료한 뒤 `Passport-1.1.1-win-x64.exe`를 실행하세요. 사용자 계정 범위로 설치하며 기존 호스트·설정·작업 배치를 유지합니다. Windows 설치본은 코드 서명을 포함하지 않습니다. Windows ARM64 설치본은 이번 배포에 포함하지 않습니다.

Windows 아이콘 수정본의 검증 소스는 [v1.1.1-win-x64-icon-fix](https://github.com/poyal/passport/tree/v1.1.1-win-x64-icon-fix)입니다. 최초 Windows 소스 태그 `v1.1.1-win-x64`, Mac 소스 태그 `v1.1.1`과 DMG는 유지합니다. 사용자의 같은 버전 수정 요청에 따라 Windows EXE와 해당 체크섬을 갱신합니다.

## 확인 범위

Finder에서 복사한 폴더의 전체 경로와 Claude Code의 이미지 첨부 표시를 사용자 환경에서 확인했습니다. 자동 검사와 최종 설치 파일의 검증 결과는 [검증 기록](https://github.com/poyal/passport/blob/main/docs/verification.md)에 남깁니다. Windows 검증은 Windows 11 x64에서 진행하며 실제 사용자 계정의 설치·업그레이드, 탐색기의 직접 복사, AI의 실제 이미지 내용 해석, 물리 IME와 OS 알림은 별도 확인 항목입니다.

Windows의 반복 재연결 진단에서는 앱 종료 후 일부 Bash 자식 프로세스가 남는 경우를 확인했습니다. 정상 앱 종료 검사와 구분해 검증 기록에 보존하며 자식 프로세스의 수명은 후속 확인 대상입니다.
