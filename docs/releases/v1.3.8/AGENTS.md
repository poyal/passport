# Passport 1.3.8 검증 기록

2026-10-30 [v1.3.8](https://github.com/poyal/passport/releases/tag/v1.3.8)을 Mac ARM64·Windows x64로 공개했습니다. 두 설치 파일과 태그의 소스는 모두 `debe7e2a8903d20149ab0a5baa53b921dcc51ca7`입니다. 이 결과를 확정한 후속 문서 커밋은 배포 바이너리의 소스가 아닙니다.

사용법은 [1.3.8 사용자 매뉴얼](README.md), 절차는 [릴리즈 가이드](../../release.md)를 따릅니다. UTF-8 기준 4 MiB 터미널 붙여넣기, 로컬 PTY·SSH 입력 순서 보존, 전송 진행 표시·용량 제한·Ctrl+C 취소를 포함합니다.

## 검증 범위와 제한

최소 지원 macOS 14 실기, 물리 IME, 실제 OS 알림, 다른 PC와의 LAN, 실제 유료 AI 서비스·설치된 AI CLI 선택 검사, 깨끗한 계정의 설치·제거·업그레이드, Docker·장시간 부하는 이번 범위에 포함하지 않았습니다. Mac은 ad-hoc 서명이며 Developer ID·Apple 공증을 포함하지 않습니다. Windows EXE에는 Authenticode 서명이 없음을 확인했습니다. 사용자 설치 앱·실제 DB는 교체하지 않았습니다.

매뉴얼은 변경되지 않은 1.3.1·1.3.5 화면을 재사용하며 새 버전 촬영으로 표시하지 않습니다. Windows 대용량 입력의 처리 완료 시간은 대상 프로그램에 따라 달라지며, 전송 완료가 대상 프로그램의 처리 완료를 뜻하지는 않습니다.
