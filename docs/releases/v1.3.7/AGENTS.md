# Passport 1.3.7 검증 기록

대상은 macOS Apple Silicon(`mac-arm64`)과 Windows 11 x64(`win-x64`)입니다. Windows 입력·개발 앱 식별자와 일반 터미널의 Codex·Claude 실행 감지 수정이 포함됩니다.

현재 상태는 후보 준비이며 두 OS의 1.3.7 정식 검증·설치 파일 게시·공개 다운로드 확인은 미실행입니다. 이전 버전이나 부분 검사의 결과를 이번 릴리즈의 통과로 사용하지 않습니다.

공개 후 검증한 소스 커밋·환경·실제 검사 결과·설치 파일 해시·서명 상태·미실행 범위를 이 문서에 확정합니다. 절차는 [릴리즈 가이드](../../release.md), 사용법은 [1.3.7 사용자 매뉴얼](README.md)을 따릅니다.
