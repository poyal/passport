# Passport 1.2.2

파일을 로컬 터미널로 끌어 넣을 때 파일 복사·붙여넣기와 같은 경로 입력을 사용하고, 드롭할 패널을 표시합니다. **macOS 14 이상·Apple Silicon용 DMG**와 **Windows 11 x64용 EXE**를 제공합니다.

## 주요 변경

- **파일·폴더 드롭:** Finder나 탐색기에서 파일이나 폴더를 로컬 터미널 본문으로 끌어 넣으면 원래 전체 경로를 셸 문법에 맞게 입력합니다. Markdown·PDF·ZIP·이미지 등 확장자에 제한을 두지 않습니다. 기존 입력을 유지하며 Enter를 자동으로 보내지 않습니다.
- **대상 패널 표시:** 드래그 중 대상 터미널 이름과 경로 추가 안내를 표시합니다. 여러 패널에서도 어느 터미널에 입력되는지 확인할 수 있습니다. 취소하거나 창을 벗어나면 안내를 지웁니다.
- **자기 자신 드롭 수정:** 왼쪽 작업 목록이나 패널 헤더에서 현재 패널 자신을 끌어 넣을 때 동작하지 않는 분할 안내가 나타나던 문제를 수정했습니다.
- **줄바꿈 단축키:** 기본 키는 **Shift+Enter**이며 **설정 → 단축키 → 줄바꿈**에서 변경·해제·초기화할 수 있습니다. 일반 Enter와 한글 입력 조합을 구분합니다. 실제 줄바꿈 처리는 이 키 입력을 지원하는 터미널 프로그램에 따라 달라집니다.
- **최초 설치 안내:** 사용자 매뉴얼에 Mac의 개발자 확인 경고와 Windows SmartScreen 경고 화면에서 확인할 절차를 추가했습니다.

## 사용 시 참고

파일 드롭은 원본 경로 입력이며 파일 복사·업로드나 AI 도구의 분석 완료를 뜻하지 않습니다. SSH 터미널에서는 파일·폴더 드롭을 지원하지 않습니다. **파일 전송**으로 업로드한 뒤 원격 경로를 사용하세요. 드롭 처리 중 연결이나 창이 바뀌면 이전 대상에 입력하지 않습니다.

기존 단축키 설정에는 줄바꿈 기본값만 추가하며 다른 사용자 지정 키와 해제 상태는 유지합니다.

## 업데이트

Mac에서는 Passport를 **⌘Q로 완전히 종료**한 뒤 새 DMG의 앱을 응용 프로그램 폴더로 옮겨 **대치**하세요. Windows에서는 Passport를 완전히 종료한 뒤 새 EXE를 실행해 기존 설치 폴더에 설치하세요. 호스트·인증·작업 배치는 유지되며 연결은 다시 시작합니다.

Mac 설치본은 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다. Windows 설치본은 코드 서명이 없습니다. 최초 실행 경고는 사용자 매뉴얼의 [Mac 안내](https://github.com/poyal/passport#mac-first-open)와 [Windows 안내](https://github.com/poyal/passport#windows-first-open)를 참고하세요. [검증 기록과 설치 파일 해시](https://github.com/poyal/passport/blob/main/docs/verification.md)에서 배포 검사 범위를 확인할 수 있습니다. Finder·탐색기의 물리 드래그, 사용자 계정 설치·업그레이드, 물리 IME·외부 AI 서비스는 별도 확인 대상입니다.
