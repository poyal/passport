# Passport 1.0.0 AI 기록

이 문서는 기존 공개 버전에 추가한 Windows 설치 파일의 소스·검증·제한을 기록합니다. 공통 절차는 [릴리즈 가이드](../../release.md), 사용법은 [1.0.0 사용자 매뉴얼](README.md)을 참고하세요.

## 소스와 공개 파일

2026-10-20 [v1.0.0](https://github.com/poyal/passport/releases/tag/v1.0.0)에 Windows x64 설치 파일을 추가했습니다. 기존 annotated 태그를 유지했으며 실제 소스는 `bc06d83d8d1158b9e69bc7d5e347d4cf8f697edc`입니다. 원본 태그의 코드·의존성 잠금 파일을 변경하지 않았습니다.

| 설치 파일 | 크기(바이트) | SHA-256 |
| --- | ---: | --- |
| `Passport-1.0.0-win-x64.exe` | 117,659,046 | `1f6ae80649eb0a47c4be935b1a6a1700bd67d39638eec51ad2b90055f6593a61` |
| 기존 `Passport-1.0.0-mac-arm64.dmg` | 154,618,392 | `06b29870ae4ecca6d8599a151aa05f0fcb3978442ca46a5f6e89ddbd9fb7a99e` |

Windows 설치 파일과 두 설치 파일을 합친 `SHA256SUMS.txt`를 공개 다운로드하여 확인했습니다. 체크섬 파일은 188바이트, SHA-256 `965c6ecdddda277a0e3f53f50ca6c9ff94c983477d8ce90967f4bba017a370ab`입니다. 기존 Mac 자산의 ID·크기·해시를 유지했습니다. 교체 직후 GitHub가 오래된 체크섬 응답을 캐시했으나, 현재 자산 ID를 붙인 인증 없는 요청과 이후 기본 공개 URL 모두 새 체크섬과 일치했습니다.

## Windows 검증

Windows 11 x64(10.0.26300), Node 24.14.0, npm 11.21.1, Electron 44.4.5, Python 3.13.7, MSVC Build Tools 2022 14.44에서 원본 태그의 빌드·시험을 수행했습니다. 이 버전에는 현재의 `release:verify`·검증 manifest·숨김 GUI 수명 감사 체계가 없습니다. 아래 결과를 최신 파이프라인 검증으로 간주하지 않습니다.

| 검사 | 결과 |
| --- | --- |
| 잠금 의존성·네이티브 모듈·타입·앱 빌드 | 통과 |
| 단위·통합 | FTP/FTPS 포함 79 통과·플랫폼 및 선택 검사 3 생략 |
| 원본 소스 전체 GUI | 22 통과·선택 검사 2 생략 |
| NSIS 빌드·페이로드 추출 | 통과 |
| 최종 설치 파일 내부 앱 smoke | 버전 1.0.0·실제 PTY·종료 코드 0 확인 |
| 설치본 GUI | 외부 실행 파일을 지원하는 구형 SSH·파일 색상 사례 2 통과 |

원본 파일 전송 시험의 심볼릭 링크 생성은 일반 권한에서 EPERM으로 실패했습니다. 사용자가 UAC 검사를 허용한 뒤 동일 소스의 단위·통합 검사를 관리자 권한으로 수행해 통과했습니다. GUI 창 표시도 사용자 허용 범위에서 수행했습니다.

구형 node-pty의 AttachConsole 진단 문구가 남지만 시험은 정상 종료했습니다. 현대적인 잔류 PTY 감사, 전체 설치본 GUI, 깨끗한 계정의 설치·제거·업그레이드, 실제 다른 PC·물리 IME는 확인하지 않았습니다. Mac 파일은 보존·해시 확인만 수행했으며 이번에 재빌드하거나 Mac 실기 검증하지 않았습니다. 사용자 설치 앱과 실제 데이터는 교체하지 않았습니다.
