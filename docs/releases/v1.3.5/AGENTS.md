# Passport 1.3.5 AI 기록

이 문서는 1.3.5의 배포 소스·검증 결과·남은 제한을 기록합니다. 공통 지침은 [루트 AGENTS](../../../AGENTS.md), 구현·E2E 규칙은 [개발 가이드](../../development.md), 검증·게시·정리는 [릴리즈 가이드](../../release.md)를 따릅니다. 사용법은 [1.3.5 매뉴얼](README.md)에서 확인합니다.

## 버전별 데이터와 동작

SQLite 스키마 7, 문서·portable 형식 2를 유지합니다. 1.3.4의 데이터 형식과 같으며 1.3.3 이하 DB는 기존 v7 이행·백업 절차를 따릅니다.

- 단일 로컬 패널 탭의 자동 아이콘은 기존 인증된 AI 연동의 Codex·Claude 실행 상태를 표시합니다. 응답 완료·입력 대기 중에는 유지하고 CLI 종료·연결 종료 시 해제합니다. 수동 아이콘을 우선하며 이름·색상만 수정하면 자동 표시를 유지합니다. 분할 탭은 기존 첫 패널 아이콘을 사용합니다.
- 호스트의 **그룹미설정** 필터는 그룹이 없는 호스트만 표시합니다. 전체 미설정 호스트 수를 표시하고 0개여도 필터를 유지합니다.
- 템플릿은 16:9 분할 미리보기, 이름 옆의 저장된 아이콘·추가 패널 수, 탭 색상, SSH·중복 제외 호스트·로컬 개수 태그를 함께 표시합니다. 실행 중인 자동 AI 아이콘은 저장하지 않습니다.

매뉴얼의 기존 전체 화면은 1.3.1 Mac 앱에서, 앱 내부 쪽지 가이드의 부분 화면은 1.3.1 Windows UI에서 격리 예제 데이터로 촬영했습니다. 변경되지 않은 이미지를 재사용하며 1.3.5 촬영본으로 표시하지 않습니다.

## 검증과 공개 상태

Mac ARM64 1.3.5 배포 후보를 준비 중입니다. 이 버전의 정식 검증·설치 파일 게시·공개 다운로드 확인은 아직 수행하지 않았습니다. 이전 버전의 검사 수와 해시를 이 버전의 결과로 사용하지 않습니다. 최종 검증 소스 커밋·환경·검사 결과·설치 파일 SHA-256·공개 상태는 실제 검증과 게시 후 확정합니다.

Windows 1.3.5는 이 Mac 작업 환경에서 검증·빌드·게시하지 않습니다. Windows 공개 설치본은 [v1.3.3](https://github.com/poyal/passport/releases/tag/v1.3.3)을 유지합니다.

## 별도 확인 범위

Windows 11 실기, macOS 14 실기, 물리 IME, OS 알림, 다른 PC의 LAN, 깨끗한 계정의 설치·제거·업그레이드, 실제 AI 유료 서비스, Docker·장시간 부하는 별도 확인 대상입니다. Mac 패키징은 기존 ad-hoc 서명이며 Developer ID·Apple 공증을 포함하지 않습니다.
