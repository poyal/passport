# Local tool icons

AI brand SVGs are vendored from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/8a1b2821bb768c484fe8da20c5e1838b6bf551a9), copyright (c) 2023 LobeHub, under the included MIT `LICENSE`.

Developer tool, language and data SVGs are vendored from [Devicon](https://github.com/devicons/devicon/tree/6a37858047b0e8d9c9c0e68f4a071fc410652e89), copyright (c) 2015 konpa, under the included MIT `DEVICON-LICENSE`.

`manifest.json` and `devicon-manifest.json` record each original path and SHA-256. SVG bytes are unchanged; Passport uses local filenames and displays the marks on white tiles in both themes. No runtime CDN or extra icon package is required. ChatGPT / GPT uses Lobe Icons' OpenAI mark.
