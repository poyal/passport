## 설치

**현재 Apple Silicon Mac용 0.3.1 테스트 설치본이 준비되어 있습니다.** Windows용 EXE는 준비 중이며, 공개 다운로드 페이지는 아직 제공하지 않습니다. 전달받은 설치 파일을 사용해 주세요.

| 내 컴퓨터                     | 설치 파일                      | 제공 상태          |
| ----------------------------- | ------------------------------ | ------------------ |
| Mac · Apple Silicon(M 시리즈) | `Passport-0.3.1-mac-arm64.dmg` | 테스트 설치본 제공 |
| Windows · Intel / AMD(x64)    | `.exe` 설치 프로그램           | 준비 중            |
| Windows · ARM64               | ARM64용 `.exe` 설치 프로그램   | 준비 중            |

### Mac

1. 전달받은 **DMG 파일**을 엽니다.
2. **Passport**를 **응용 프로그램(Applications)** 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 Passport를 실행합니다.

Apple Silicon 전용으로 Rosetta가 필요하지 않습니다. Intel Mac은 지원하지 않습니다. macOS 14 이상을 대상으로 하며 현재 macOS 27에서 확인했습니다. 테스트 설치본은 Apple의 배포 공증을 받지 않아 최초 실행 시 보안 안내가 표시될 수 있습니다.

### Windows

EXE 제공 후 컴퓨터에 맞는 설치 프로그램을 실행하고, 설치 위치를 선택한 뒤 시작 메뉴에서 Passport를 열면 됩니다. Windows 11의 x64·ARM64를 대상으로 하며 실제 설치·실행 확인이 남아 있습니다.

## 주요 기능

| 기능                 | 할 수 있는 일                                                          |
| -------------------- | ---------------------------------------------------------------------- |
| **호스트 관리**      | 서버를 그룹·태그·즐겨찾기로 정리하고 여러 호스트의 설정을 한 번에 변경 |
| **탭과 분할 터미널** | SSH 연결을 탭으로 열고 드래그로 분할, 크기 조절, 별도 창으로 이동      |
| **양쪽 파일 탐색**   | 로컬·SFTP·FTP·명시적 FTPS 연결, 드래그와 우클릭 메뉴로 파일 전송       |
| **명령어 스니펫**    | 자주 쓰는 명령을 저장하고 선택한 터미널 또는 현재 탭 전체에 전달       |
| **테마와 글꼴**      | 기본 테마 12종, 사용자 테마, 글꼴·크기·간격·커서·로그 강조 설정        |
| **내 작업 환경**     | 로컬 터미널, 포트 포워딩, 최대 30일 자동 로그 기록, 파일로 설정 내보내기  |

### 호스트를 정리하고 빠르게 연결

이름·주소·계정·태그로 검색하고, 그룹에 공통 설정을 지정하세요. 호스트를 두 번 클릭하면 연결됩니다.

![그룹과 태그로 정리한 Passport 호스트 목록](docs/assets/hosts.png)

### 서로 다른 서버도 같은 화면에서

좌우 패널에 각각 컴퓨터나 서버를 선택하세요. 우클릭으로 복사·이름 변경·새 폴더·권한 변경을 사용하고, 아래 전송 목록에서 결과를 확인할 수 있습니다.

![Passport 양쪽 SFTP 파일 목록과 우클릭 메뉴](docs/assets/files.png)

### 오래 보는 터미널을 내 취향대로

앱의 라이트·다크 모드와 터미널 테마를 따로 선택할 수 있습니다. 폰트와 크기를 바꾸고 로그·주소 강조로 필요한 출력을 찾아보세요.

![Passport 터미널 외형 패널과 테마 목록](docs/assets/appearance.png)

## 시작하기

1. **호스트 → 새 호스트**에서 서버 주소·포트·사용자 이름을 저장합니다.
2. 호스트를 두 번 클릭하고 비밀번호나 SSH 개인 키로 연결합니다. 처음 연결하는 서버는 SSH 지문을 확인합니다.
3. 탭을 다른 탭 위에 잠시 올린 뒤 터미널 가장자리로 드래그하면 분할됩니다. 분할 경계를 끌어 크기를 조절하세요.
4. **파일**에서 좌우 연결을 선택하고 파일을 반대편으로 드래그하거나 우클릭 메뉴로 복사합니다.

명령어 저장, 여러 창에 붙여넣기, 로그와 포트 포워딩은 [사용 안내](docs/user-guide.md)에서 확인하세요.

## 내 설정을 다른 컴퓨터로

**설정 → 내보내기와 백업**에서 호스트·그룹·스니펫·작업 배치·설정을 파일로 내보내고 다른 컴퓨터에서 가져올 수 있습니다. 비밀번호와 개인 키는 기본적으로 제외하며, 포함할 때는 별도의 암호로 보호합니다.

작업 배치는 자동 저장되며 앱을 다시 열면 직접 재연결합니다. 자동 업데이트는 제공하지 않습니다. 새 버전을 설치할 때도 설정을 먼저 내보내고 새 DMG 또는 EXE를 설치해 주세요.
