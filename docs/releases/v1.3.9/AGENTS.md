# Passport 1.3.9 검증 기록

2026-10-31 [v1.3.9](https://github.com/poyal/passport/releases/tag/v1.3.9)을 Mac ARM64·Windows x64로 공개했습니다. 두 설치 파일과 태그의 소스는 `0cc2394ef072c585a4a6925a3c924de063bdf99d`입니다. 사용자의 게시 진행 신호 후 검증한 파일을 재빌드 없이 게시했습니다. 이 결과를 확정한 후속 문서 커밋은 배포 바이너리의 소스가 아닙니다.

사용법은 [1.3.9 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

## 부하·실기 결과

각 OS의 소스와 설치본에서 터미널 16개 × 100 KiB/s를 10분 유지하고, 같은 출력에 SFTP 작업·외형 변경·5회 재로드와 SSH 재연결을 섞은 30분 검사를 추가로 통과했습니다. 재연결마다 이전 SSH 채널 16개가 회수됐습니다.

| 대상 | 부하 | 입력 왕복 p95(ms) | 렌더 p95(ms) | 앱 최대 working set(MiB) | 워밍업 후 증가(MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| Windows 소스 | 10분 / 30분 | 23.2 / 21.3 | 29.2 / 28.6 | 1431 / 1688 | -10.4 / 145.1 |
| Windows 설치본 | 10분 / 30분 | 20.0 / 21.7 | 26.4 / 28.9 | 1432 / 1669 | 13.3 / -11.0 |
| Mac 소스 | 10분 / 30분 | 16.8 / 17.2 | 44.1 / 43.5 | 1125 / 1464 | 1.2 / 13.1 |
| Mac 설치본 | 10분 / 30분 | 16.4 / 16.3 | 42.8 / 42.7 | 1136 / 1402 | 0.2 / 69.8 |

입력 수치는 SSH/IPC 왕복, 렌더 수치는 DOM 갱신 후 프레임 관찰입니다. 물리 키 입력·IME·모니터 표시 지연이 아닙니다. Windows 숨김 검사는 offscreen 렌더링을 사용하며 실제 창의 포커스·클립보드·레이아웃은 별도 데스크톱 검사로 확인했습니다. 1 GiB까지의 Unicode/ANSI 출력과 64 KiB 긴 줄도 수신량·최종 표시 마커·프레임·메모리 기준을 통과했습니다. 무제한 출력의 포화 부하에서는 Windows 입력 응답 p95가 약 2.6초였으므로 위 16패널 일정 속도 측정과 구분합니다.

4 GiB 파일 SHA-256과 10,000개 작은 파일의 내용을 양쪽 OS에서 대조했습니다. 파일 SHA-256은 `624a0613f0b0a1c4022c3ea2ba081f7c62d4179d057b222a471a1e413897a731`입니다. Mac 정식 단위 실행은 10,982ms·RSS 증가 434 MiB, Windows의 같은 최종 소스 후속 측정은 31,293ms·432 MiB였습니다. Windows 정식 단위 통과와 별도로 stdout 원본 수치를 남긴 후속 측정임을 구분합니다.

최종 설치본의 추가 실기는 다음과 같습니다.

- Windows–Mac의 서로 다른 실제 LAN 주소에서 직접 TLS로 친구 등록·수신 승인·양방향 8 MiB 첨부·실제 터미널 CLI 전달을 확인했습니다. SSH 포워딩을 통한 Docker 검증과 별개입니다. 첨부 SHA-256은 `0b8d4e1d3ee9d8d123662800493da602976bc63bd4fdc9092f89f0ece95bd382`이며, HTML 비실행·Windows ZoneId 3·Mac quarantine·거절·친구 삭제 후 차단도 통과했습니다.
- 각 OS에서 밝은/어두운 테마, 폭 1024/1440의 외형·터미널·쪽지 화면 12장을 확인했습니다. 테마 전환 완료 후 아이콘·배경색도 대조했습니다.
- 실제 창의 모든 주요 화면·설정, 최소·일반·넓은 창 크기와 두 테마 검사는 Windows 1개·Mac 1개가 각각 통과했습니다. 각 실행의 앱 시작·종료·감사는 1/1/1, 표시 1·포커스 0입니다.

## 검증 범위와 제한

물리 한글 IME 조합, 최소 지원 macOS 14 실기, 깨끗한 계정에서의 설치·업그레이드·제거, OS 알림의 실제 전달, 로그인한 외부 AI 서비스는 미검증입니다. 실제 키체인 승인·OS 암호화, 네이티브 데스크톱, 설치된 AI CLI와 두 PC LAN은 위 범위에서 확인했습니다. Mac은 ad-hoc 서명이며 Developer ID·Apple 공증을 포함하지 않고 Windows EXE에는 Authenticode 서명이 없습니다. 사용자 설치 앱·실제 DB는 교체하지 않았습니다.

매뉴얼은 변경되지 않은 1.3.1·1.3.5 화면을 재사용하며 새 버전 촬영으로 표시하지 않습니다. 정식 검증·공개 다운로드·최종 문서 확정 후 작업용 Docker·포워딩·LaunchAgent·마운트·격리 프로필과 빌드·시험 산출물을 정리했습니다.
