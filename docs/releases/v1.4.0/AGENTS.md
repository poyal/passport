# Passport 1.4.0 검증 기록

현재 1.4.0은 게시 준비 중이며 정식 릴리즈 검증과 공개 다운로드 확인은 아직 수행하지 않았습니다. 현재 공개 버전은 1.3.10입니다.

사용법은 [1.4.0 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

## 후보 범위

Mac ARM64와 Windows x64에 앱 내 다운로드·업데이트 서명 검증·재시작 후 교체를 추가합니다. 시작 실패 시 앱과 데이터베이스를 복구하는 updater와 버전 간 업데이트 검증을 포함합니다. 기존 1.3.10 사용자는 최초 전환 버전을 한 번 직접 설치해야 합니다.

## 검증 상태

두 OS의 후보 소스 커밋, 정식 검증 환경, 설치 파일 해시, 최종 결과는 아직 확정되지 않았습니다. 개발 중 임시 99.0.1에서 99.0.2로 수행한 격리 업데이트 검사는 양쪽 OS에서 설정과 실제 암호화 인증정보 보존까지 통과했지만, 이 결과는 1.4.0 배포 바이너리의 정식 검증 증거가 아닙니다.

사용자가 두 OS의 실제 데스크톱 검사를 허용했습니다. 최초 전환 검증에는 같은 배포 키를 포함한 격리된 1.3.11 시험 빌드를 사용하며, 이 시험 빌드는 공개하지 않습니다. 배포용 공개 키 PEM의 SHA-256은 `e7e95b0a32f3b491e6f3f17b1fc919ff4c211e2632d88d892bb3d2dbe67ad5d4`입니다. 개인 키는 저장소 밖의 사용자 전용 보관 폴더에 유지합니다.

## 제한

Mac은 ad-hoc 서명이며 Apple Developer ID·공증을 포함하지 않습니다. 업데이트 패키지의 Ed25519 서명은 OS 게시자 인증과 별개입니다. 최초 설치 보안 승인과 키체인 요청, Gatekeeper·SmartScreen의 실제 화면, 최소 지원 OS 실기는 숨김 업데이트 시험만으로 검증되지 않습니다. 사용자 설치본과 실제 데이터는 격리 시험 대상으로 사용하지 않습니다.
