# Passport 1.2.1

단축키 편집을 간단하게 바꾸고 앱의 버튼 모양과 설정 화면 간격을 맞췄습니다. 이번에는 **macOS 14 이상·Apple Silicon용 DMG**를 먼저 제공합니다. Windows x64 설치 파일은 후속 검증 뒤 같은 릴리즈에 추가할 예정이며, 그전에는 [Windows 1.2.0](https://github.com/poyal/passport/releases/tag/v1.2.0)을 사용해 주세요.

## 주요 변경

- **단축키 변경·해제·초기화:** 기능마다 키 하나를 지정합니다. **설정 → 단축키 → 키 변경**에서 키를 누르고 **적용**한 뒤 **단축키 저장**을 누르세요. **X**는 해제, **초기화**는 해당 기능의 기본 키 복원입니다.
- **키 표시와 버튼 통일:** 키 조합은 텍스트로 표시하며 `키 변경`·X·`초기화`와 앱의 일반 동작 버튼에 같은 배경·테두리·모서리를 사용합니다.
- **설정 화면 간격:** 업데이트 결과와 안내문, 제목과 버튼, 글꼴 라벨과 입력칸, 프로파일·포트 포워딩 대화상자의 간격을 정리했습니다. 작은 창과 다크·라이트 테마에서도 확인했습니다.

## 기존 단축키와 백업

한 기능에 여러 키를 지정했던 설정은 **첫 번째 키만 유지**합니다. 두 OS의 설정과 기존 백업 가져오기에 동일하게 적용하며, 해제한 기능은 그대로 해제 상태를 유지합니다. 업데이트 후 **설정 → 단축키**에서 지정된 키를 확인하세요.

## 업데이트와 확인 범위

Passport를 **⌘Q로 완전히 종료**한 뒤 새 DMG의 앱을 응용 프로그램 폴더로 옮겨 **대치**하세요. 호스트·인증·작업 배치는 유지되며 연결은 다시 시작합니다.

Mac 설치본은 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다. Mac 검증 결과와 설치 파일 해시는 [검증 기록](https://github.com/poyal/passport/blob/main/docs/verification.md)에 기록합니다. Windows 실기·EXE 배포는 이번 Mac 배포에 포함하지 않습니다. 사용자 계정 설치·업그레이드, 물리 IME, OS 알림과 외부 AI 서비스는 자동 검사와 별도로 확인합니다.
