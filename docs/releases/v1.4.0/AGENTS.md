# Passport 1.4.0 검증 기록

[Passport 1.4.0](https://github.com/poyal/passport/releases/tag/v1.4.0)은 Mac ARM64·Windows x64로 공개되었습니다. 배포 소스는 두 OS 모두 `9a8f5f15a7ae0c30704593ad49684c776467a50e`, 태그는 `v1.4.0`입니다. 이 결과를 확정한 후속 문서 커밋은 바이너리 소스와 구분하며 태그를 이동하지 않았습니다.

사용법은 [1.4.0 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

데스크톱 단계는 소스·설치본 각각 4개 사례를 별도로 실행했습니다. 숨김 감사 수치로 물리 화면 동작을 대신하지 않습니다. 정상 종료는 코드 0·시그널 없음·기존 10초 제한을 유지합니다. Windows 잔류 PTY 감사도 통과했습니다.

최종 검증은 4 MiB Unicode 입력의 바이트·SHA-256을 확인하는 Rust PTY 수신기, 실제 출력으로 셸 생존을 확인하는 창 닫기 시험, 사용자 설정과 분리한 Codex 알림 fixture를 사용했습니다. Windows 검증 프로세스의 ORIGINAL_PATH 간섭을 제거하고 Mac 후보의 실제 키체인 접근을 준비한 뒤, 같은 최종 커밋에서 두 OS 전체 정식 검증을 통과했습니다. 시험 제한 시간과 사용자 설정은 변경하지 않았으며 실패한 중간 결과는 배포 증거에 포함하지 않았습니다.

## 앱 내 업데이트 실기

두 OS에서 동일 배포 키를 포함한 비공개 1.3.11 시험 앱을 격리 설치한 뒤 정식 1.4.0 업데이트 ZIP으로 교체했습니다. 실제 다운로드·서명 검증·이전 앱 정상 종료·별도 updater 교체·새 앱 시작 확인·재실행·설정 보존·저장된 인증정보의 OS 암호화 복원을 통과했습니다. Mac은 Keychain, Windows는 DPAPI를 사용했으며 `nativeEncryption: true`, `credentialsRestored: true`입니다. GitHub 최신 버전 조회만 시험 응답을 사용하고 실제 서명된 ZIP은 루프백 HTTP로 전달했습니다. 사용자 설치 앱·실제 DB는 교체하지 않았습니다.

1.3.11은 최초 전환 검증용이며 공개하지 않았습니다. 1.3.10 이하 공개 앱에는 이 updater가 없으므로 사용자는 1.4.0을 한 번 직접 설치한 뒤 이후 업데이트를 앱에서 적용합니다. 앱 설치 경로에 쓰기 권한이 필요하며 관리자 권한 상승은 구현하지 않았습니다.

배포 공개 키 SPKI PEM의 SHA-256은 `e7e95b0a32f3b491e6f3f17b1fc919ff4c211e2632d88d892bb3d2dbe67ad5d4`입니다. 사용자 요청에 따라 같은 개인 키를 Windows `%LOCALAPPDATA%/PassportRelease`와 Mac `~/.config/passport-release`의 사용자 전용 권한으로 보관했습니다. 저장소·앱·로그에는 개인 키를 포함하지 않습니다.

## 제한과 정리

Mac은 ad-hoc 코드 서명이며 Developer ID·Apple 공증이 없습니다. Windows Authenticode 서명도 포함하지 않습니다. 업데이트의 Ed25519 서명은 OS 게시자 인증을 대신하지 않습니다. DMG 무결성·실제 Keychain 왕복·설치본 실행은 확인했지만, 최초 승인 뒤 업데이트마다 보안 설정 재방문이 없는지에 대한 Gatekeeper·TCC 실기, SmartScreen 화면, 최소 지원 OS는 별도로 검증하지 않았습니다. 키체인 요청과 보안 설정 화면은 다른 동작입니다.

깨끗한 사용자 계정의 설치·제거, 물리 한글 IME, 실제 OS 알림, 로그인한 외부 AI 서비스, 다른 PC와의 LAN 승인, Docker·장시간 부하·실제 AI CLI 선택 검사는 이번 정식 실행 범위에 포함하지 않았습니다. 이 항목은 자동 검사 통과로 표시하지 않습니다.

공개 확인과 최종 기록 이후 임시 앱·검증 로그·빌드 결과·작업 전용 도구 및 Mac 일회성 LaunchAgent를 정리했습니다. 사용자 설치본·데이터와 양쪽의 영구 업데이트 서명 키는 보존했습니다.
