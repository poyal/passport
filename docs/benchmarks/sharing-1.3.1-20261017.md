# 공유 1.3.1 변경 검증 — 2026-10-17

공개 게시 전 작업 기록이다. 기존 Mac 1.3.0 설치 파일과 태그는 변경하지 않았다. 사용자가 Mac 검색 결함 수정과 공유 화면 개선을 1.3.1에 함께 반영하도록 요청했다.

## 구현과 검증 범위

- mDNS는 UDP 수신을 wildcard에 바인딩하고 multicast membership·발신 인터페이스와 광고 주소는 선택한 NIC로 제한한다. bonjour-service의 내부 multicast-dns 비동기 오류도 처리한다. 원래 Mac 옵션의 `EADDRINUSE` 및 수정 모듈의 실제 LAN 양방향 검색은 이전 원격 검사에서 확인했다. 사용자가 본 JavaScript 오류창 원문은 확보하지 못했으므로 같은 원인이라고 확정하지 않는다. **수정 앱의 Mac 패키지 실기는 아직 진행 중이다.**
- 새 발신은 메시지 단독 또는 메시지+첨부 하나다. 파일만 발신하지 않는다. 메시지+파일은 한 요청·한 승인으로 처리하며 메시지와 파일의 크기·해시를 각각 검증한다. 메시지 저장 또는 파일 보호 실패 시 새 첨부를 공개하지 않는다. 예전 앱의 파일 수신 형식은 읽을 수 있지만 새 첨부 메시지는 양쪽 모두 1.3.1이 필요하다.
- Tiptap 3.32.0 서식 편집, Markdown 원문, 검색형 받는 사람, 받은 메시지 검색·독립 스크롤, 첨부 정보·수동 열기·경로 복사, 아이콘 작업 버튼을 추가했다. 외부 HTML 붙여넣기는 일반 텍스트만 가져온다. 본문 링크·이미지·스크립트는 수신 뷰어에서 실행하지 않는다.
- 친구 수정은 이름·주소를 한 번에 검증한 뒤 저장한다. 이름만 바꾸면 연결을 끊지 않는다. 삭제는 인증 신뢰·진행 전송·등록을 제거한다. 별도 차단 기능은 제거했고 1.3.0에서 차단한 친구는 암호화 주소록을 열 때 삭제한다.
- VPN 지원은 사용자 요청으로 철회했다. 같은 LAN을 지원하며 CGNAT 전용 주소 범위는 제외했다. 사설 IP만 보고 VPN 인터페이스인지 판별해 모든 VPN을 기술적으로 차단한다고 주장하지 않는다.

Windows 공유 단위/통합 검사 20개 통과. 실제 loopback TLS, 암호화 저장, 메시지/첨부 승인, 무결성·저장 실패·삭제·이벤트 수명을 검사한다. 단위 검사의 OS 보호 주입을 네이티브 검사로 표시하지 않는다.

Windows 숨김 공유 E2E 3개 통과: 서식 편집과 왕복 전송, 원문 유지·초안 복구, 비활성 실행 문법, 첨부 선택·취소·제거, 한 번 승인, 경로 복사·명시적 파일 열기·이동된 파일 오류, 친구 수정 실패의 원자성·검색·삭제, 실제 CLI. 파일 열기는 OS 경계만 캡처했고 사용자의 기본 앱을 열지 않았다. 앱 5회·창 5개·정상 종료와 감사 각 5회, 표시·네이티브 포커스 0회. 증거: `release/checks/20261016T150553Z-bae6764-dirty-win-x64-e2e-hidden/`.

검토용 화면과 샘플은 `release/checks/20261016T150000Z-v1.3.1-review/`에 보관한다. 사용자 DB와 별도의 실제 DPAPI 프로필이며 샘플은 Git에 넣지 않는다. 메시지 40개·loopback 전용 친구 샘플과 실제 승인 대기 요청을 준비한다. 샘플의 목록 제목도 실제 수신처럼 본문 첫 줄에서 파생한다. 샘플은 실제 동료가 보낸 기록이 아니다.

## 쪽지 명칭·가이드·승인 대기 통합 후속

쪽지 화면의 요청을 받은 목록에 통합하고 전체·승인 대기·받은 쪽지 필터를 추가했습니다. 대기 요청은 주황색·시계, 받은 쪽지는 체크 아이콘으로 구분합니다. 목록 선택 경합을 막고 승인 완료 뒤 본문으로 이어집니다. 사용가이드의 실제 화면 PNG, 명령·AI 안내문 복사를 추가했습니다. 실행 중인 개발 화면에서 빌드 자산을 교체해 이전 이미지 해시를 찾지 못한 현상은 최신 화면을 다시 불러와 해소했고, 새 앱의 이미지 naturalWidth 검사도 통과했습니다. 정식 설치본은 고정 자산으로 재검증합니다.

Windows 관련 숨김 GUI: `release/checks/20261016T153650Z-ed717aa-dirty-win-x64-e2e-hidden/`, 3개 통과·5회 정상 종료·표시/포커스 0회. 여러 친구 등록 후 TLS ECONNRESET을 재현하고 발신 기기의 지문별 SNI 컨텍스트를 적용해 수정했습니다. 일반 TLS CA 검증과 정확한 인증서 핀 검사를 유지하며, 21개 쪽지 단위/통합과 별도 위장 SNI·미등록·삭제 친구 회귀를 통과했습니다. 구형 발신자의 공통 SNI는 기존 경로이므로 양쪽 1.3.1 업데이트를 안내합니다.
