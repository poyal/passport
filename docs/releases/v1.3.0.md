# Passport 1.3.0

등록한 친구와 승인한 메시지·파일을 주고받는 공유함을 추가하고, 탭 구분·연결 복구·AI 알림을 개선합니다.

**Mac ARM64 1.3.0을 먼저 배포합니다.** Windows 최신 설치본은 [1.2.3](https://github.com/poyal/passport/releases/tag/v1.2.3)입니다. Windows 1.3.0 설치본은 이번 릴리즈에 포함하지 않습니다.

사용자 요청에 따라 실제 OS 보안 기능·두 PC 간 LAN/VPN·데스크톱 검증을 추후로 미루고, 전체 숨김 검증을 통과한 Mac 설치본을 재빌드 없이 게시합니다. 해당 실기 검증과 공유 보안 검토의 최종 통과는 아직 완료되지 않았습니다. 공유 기능은 기본으로 꺼져 있습니다.

## 주요 변경

- **공유함:** 받은 메시지를 먼저 표시하고 **보내기**, **내 친구** 탭을 분리합니다. 등록키 복사와 상대의 등록 승인으로 친구를 추가하고, 별칭은 각 사용자가 정합니다.
- **승인 후 수신:** 메시지와 파일은 매번 받는 사람이 승인해야 본문을 보냅니다. 메시지는 Markdown으로 표시하고 복사만 지원하며, 파일은 지정 폴더에 저장합니다. 링크·이미지를 외부에서 불러오거나 파일을 실행하지 않습니다.
- **공유 설정:** 사용할 네트워크·다운로드 폴더·주변 검색을 설정합니다. 받은 메시지는 기본 7일 후 정리하며 정리 안 함 또는 1–30일을 선택할 수 있습니다. 다운로드 파일은 자동 삭제하지 않습니다.
- **공유 CLI:** `passport share friends --json`으로 친구 별칭과 기기 ID를 확인한 뒤 `send`, `status`, `cancel`을 사용할 수 있습니다. 받은 본문 읽기와 수신 승인은 CLI에 제공하지 않습니다.
- **탭 설정:** 상단 **탭 설정** 또는 왼쪽 탭의 우클릭 메뉴로 이름·OS 아이콘·이모지·색상을 바꿉니다. 탭 색상은 상단에도 연하게 표시하며, 여러 패널은 `+1`, `+2`처럼 표시합니다. 왼쪽 탭은 그대로 드래그해 순서를 바꿉니다.
- **연결 복구:** 끊긴 연결이 있을 때만 연결 개수 옆에 복구 아이콘이 나타납니다. 한 번 눌러 현재 탭의 끊긴 연결을 다시 연결합니다.
- **알림과 터미널:** 승인 요청·입력 대기 등 사용자의 개입이 필요한 AI 상태 알림을 보강하고, 로컬 셸에서 SSH로 접속한 뒤 여러 줄을 붙여넣는 동작을 수정합니다. 호스트 그룹과 탭 편집 접근도 개선합니다.
- **보안 보강:** 공유 기기키의 동시 초기화를 직렬화하고, 설정 초기화 뒤 오래된 작업이 키를 복원하지 않도록 차단합니다. 느린 상대의 응답에도 전체 요청 시간 제한을 적용합니다. Electron을 44.8.0으로 갱신합니다.
- **Windows 내장 셸 준비:** 소스의 Git for Windows 고정 버전을 2.56.0.windows.2로 갱신합니다. OpenSSL 3.5.9 보안 패치와 Git 실행 파일의 서명 복구를 포함하며, Windows 설치본 검증·배포는 별도입니다.

## 공유 시작하기

1. **설정 → 공유**에서 사용할 네트워크와 다운로드 폴더를 선택하고 공유 설정을 적용합니다.
2. **공유함 → 등록키 복사**로 복사한 키를 상대에게 별도로 전달합니다. 상대가 등록을 요청하면 별칭을 정해 승인합니다.
3. **공유함 → 보내기**에서 받는 사람을 선택해 메시지나 파일을 보냅니다. 상대가 승인하면 수신이 진행됩니다.
4. CLI를 사용할 때는 공유를 켠 뒤 새 로컬 터미널을 열고 `passport share friends`부터 실행합니다.

등록키는 5분, 수신 요청은 10분 후 만료됩니다. 메시지는 UTF-8 256 KiB, 파일은 허용 확장자 하나당 100 MiB까지입니다. [공유 안내](../sharing.md)에서 허용 형식·암호화·보관·AI 사용 순서를 확인하세요.

## 보안과 업데이트 시 참고

전송은 TLS 1.3과 기기 인증서를 사용합니다. 개인키·친구 목록·받은 메시지는 OS 암호화 저장소를 사용해 보관하며, 다운로드 파일은 일반 파일입니다. 확장자 검사와 OS 다운로드 보호가 첨부 파일의 무해함을 보증하지는 않습니다.

공유는 기본으로 꺼져 있습니다. 업데이트 전 Passport를 완전히 종료하고 해당 OS의 기존 앱을 대치합니다. 호스트·인증·설정·작업 배치는 유지되며 연결은 다시 시작합니다. 개발 앱의 데이터는 정식 앱으로 자동 복사되지 않습니다.

Mac 설치본은 ad-hoc 서명이며 Apple 공증을 포함하지 않습니다. 기존 Windows 1.2.3 설치본은 코드 서명이 없습니다. 수행 검사와 남은 보안 검증은 [검증 기록](../verification.md), [보안 재검토](../security-review-20261016.md)에 구분해 기록합니다.
