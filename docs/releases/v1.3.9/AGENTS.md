# Passport 1.3.9 검증 기록

1.3.9는 Mac ARM64·Windows x64 검증 후보이며 아직 공개하지 않았습니다. 현재 공개 버전은 [1.3.8](https://github.com/poyal/passport/releases/tag/v1.3.8)입니다. 사용자의 게시 보류에 따라 정식 검증·설치 파일 준비까지 수행하고, 공개 태그와 GitHub Release 게시는 별도 진행 신호를 기다립니다.

사용법은 [1.3.9 사용자 매뉴얼](README.md), 공통 절차는 [릴리즈 가이드](../../release.md)를 따릅니다.

## 후보 검증 상태

정식 검증은 아직 완료하지 않았습니다. 개발 중 변경된 소스로 통과한 검사와 이전 버전 결과를 최종 설치 파일의 증거로 사용하지 않습니다. 두 OS의 동일한 깨끗한 소스에서 단위·정책·소스 GUI·실제 데스크톱·설치 파일 GUI를 통과한 뒤 실행 ID·커밋·설치 파일 해시를 확정합니다.

## 대상 범위와 제한

터미널 Unicode 출력·세대별 ACK/리사이즈·화면 복원·종료 직전 출력, SSH 재연결과 터널 취소, AI 대화 복구, 데이터 복구·저장 실패·UI 안내, 17개 기능군의 IPC·시나리오 연결을 검증합니다. 쪽지 전달·수신 성공은 오류와 구분한 정상 알림으로 표시합니다. 선택 검사는 실제 Codex·Claude CLI, Docker Linux SSH/SFTP, 16개 터미널의 10분·30분 부하, 큰 텍스트 출력, 4 GiB·10,000개 파일 전송을 포함합니다. 실제 Windows–Mac LAN 전송은 별도로 확인합니다.

실제 AI CLI의 모델 응답은 격리된 루프백 서버에서 제공하므로 유료 AI 서비스 검증을 뜻하지 않습니다. 네이티브 CLI 시작 훅이 오지 않는 경우에도 기존에 확인한 대화를 정확히 같은 재개 명령·작업 폴더·설정 위치로 실행할 때 ID를 보존합니다. 새 PTY 출력과 새 요청으로 실제 재개를 확인합니다.

자동 입력·Unicode 파일 바이트 검사는 사람이 사용하는 모든 물리 IME 조합을 대신하지 않습니다. 최소 지원 macOS 14 실기, 깨끗한 계정에서의 설치·업그레이드·제거, OS 알림·권한 창은 해당 실행을 확인하기 전까지 미검증입니다. Mac 후보는 ad-hoc 서명이며 Apple 공증을 포함하지 않습니다. 새 후보의 키체인 승인 여부는 설치 파일 검증 단계에서 확인합니다.

## 의존성

Electron 44.10.0, Vite 8.3.5, Vitest 4.1.12, Zod 4.6.7로 갱신했습니다. 2026-10-31 개발 시점 npm audit의 high·critical은 0이고 런타임 의존성(`--omit=dev`)은 전체 0건입니다. electron-builder 계열의 minimatch 개발 전이 의존성 moderate 15건은 남아 있습니다. 주요 버전 강제 교체로 패키징 도구의 호환성을 깨뜨리는 자동 수정을 적용하지 않았습니다. 정식 후보에서 설치 파일과 의존성을 함께 확인합니다.
