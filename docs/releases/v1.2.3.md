# Passport 1.2.3

Passport 안의 스크립트·AI 도구에서 다른 로컬 터미널의 화면을 읽고 입력을 보낼 수 있는 CLI를 추가했습니다. 이번 릴리즈는 **Windows 11 x64용 EXE만** 제공합니다. Mac의 최신 공개 버전은 [1.2.2](https://github.com/poyal/passport/releases/tag/v1.2.2)이며 이 CLI 기능은 포함되지 않습니다.

## 주요 변경

- **내 패널 확인:** `passport identify`로 현재 패널 ID와 탭 이름을 확인하고, `passport list`로 모든 창의 로컬 패널을 조회합니다.
- **입력과 키 전송:** `passport send --pane ID '내용'`으로 특정 패널에 입력하고 `passport key --pane ID enter`로 키를 보냅니다. 파일·표준입력을 지원하며 `--submit`을 지정하면 Enter까지 전달합니다.
- **화면 읽기:** `passport read --pane ID --lines 20`으로 대상 패널에 남아 있는 최근 화면 텍스트를 읽습니다. 비활성 패널·다른 창·TUI의 별도 화면도 지원합니다.
- **접근 설정:** **설정 → 로컬 터미널 → CLI 접근**에서 **끔 / 조회만 / 조회·입력**을 선택합니다. 기본은 **끔**이며 변경한 뒤 새 로컬 터미널을 열거나 재연결해야 합니다.
- **개발 빌드 구분:** 개발 앱은 `Passport-dev`, 버전은 `-dev` 접미사를 사용하며 정식 앱과 별도의 데이터 폴더에 저장합니다.

## 시작하기

1. **설정 → 로컬 터미널 → CLI 접근 → 조회·입력**을 선택합니다.
2. **새 로컬 터미널**을 엽니다. 이미 열린 터미널에는 새 권한이 적용되지 않습니다.
3. `passport identify`와 `passport list`를 실행해 패널 ID를 확인합니다.

별도 CLI 설치나 시스템 PATH 수정은 필요하지 않습니다. [사용자 매뉴얼](https://github.com/poyal/passport#terminal-cli)과 [명령·Bash·PowerShell 예제](https://github.com/poyal/passport/blob/main/docs/terminal-cli.md)를 참고하세요.

## 사용 시 참고

CLI는 Passport의 로컬 패널에만 접근하며 등록된 SSH 패널은 지원하지 않습니다. 기본 `send`는 Enter를 보내지 않습니다. 전송 성공은 터미널 입력을 전달했다는 뜻이며 AI 작업 완료를 보장하지 않습니다. 화면 읽기는 현재 터미널 버퍼를 사용하며 별도 대화 기록을 만들지 않습니다.

권한을 변경하면 기존 CLI 자격은 즉시 폐기됩니다. 여러 줄 입력은 대상 프로그램이 bracketed paste를 지원해야 합니다. `--json`으로 결과를 처리할 수 있습니다.

## 업데이트

Passport를 완전히 종료한 뒤 `Passport-1.2.3-win-x64.exe`를 실행해 기존 설치 폴더에 설치하세요. 호스트·인증·설정·작업 배치는 유지되며 연결은 다시 시작합니다. CLI 접근은 업데이트 뒤에도 기본으로 꺼져 있습니다.

개발 앱 `Passport-dev`의 설정은 정식 앱으로 자동 복사되지 않습니다. Windows 설치본은 코드 서명이 없습니다. 최초 실행 경고는 [Windows 안내](https://github.com/poyal/passport#windows-first-open)를 참고하세요. [검증 기록](https://github.com/poyal/passport/blob/main/docs/verification.md)에서 수행한 검사 범위를 확인할 수 있습니다. 사용자 계정 설치·제거·업그레이드, 물리 IME·OS 알림·실제 AI 서비스는 별도 확인 대상입니다.
