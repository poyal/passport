# Passport 1.3.5 AI 기록

이 문서는 1.3.5의 배포 소스·검증 결과·남은 제한을 기록합니다. 공통 지침은 [루트 AGENTS](../../../AGENTS.md), 구현·E2E 규칙은 [개발 가이드](../../development.md), 검증·게시·정리는 [릴리즈 가이드](../../release.md)를 따릅니다. 사용법은 [1.3.5 매뉴얼](README.md)에서 확인합니다.

## 버전별 데이터와 동작

SQLite 스키마 7, 문서·portable 형식 2를 유지합니다. 1.3.4의 데이터 형식과 같으며 1.3.3 이하 DB는 기존 v7 이행·백업 절차를 따릅니다.

- 단일 로컬 패널 탭의 자동 아이콘은 기존 인증된 AI 연동의 Codex·Claude 실행 상태를 표시합니다. 응답 완료·입력 대기 중에는 유지하고 CLI 종료·연결 종료 시 해제합니다. 수동 아이콘을 우선하며 이름·색상만 수정하면 자동 표시를 유지합니다. 분할 탭은 기존 첫 패널 아이콘을 사용합니다.
- 호스트의 **그룹미설정** 필터는 그룹이 없는 호스트만 표시합니다. 전체 미설정 호스트 수를 표시하고 0개여도 필터를 유지합니다.
- 템플릿은 16:9 분할 미리보기, 이름 옆의 저장된 아이콘·추가 패널 수, 탭 색상, SSH·중복 제외 호스트·로컬 개수 태그를 함께 표시합니다. 실행 중인 자동 AI 아이콘은 저장하지 않습니다.

매뉴얼의 그룹미설정·템플릿 화면은 최종 1.3.5 Mac 앱을 숨김 모드·1360×850·격리 예제 데이터로 촬영했습니다. 서버 주소는 문서용 `192.0.2.0/24`이며 실제 연결·사용자 데이터는 사용하지 않았습니다. 나머지 전체 화면은 1.3.1 Mac 앱, 앱 내부 쪽지 가이드 부분 화면은 1.3.1 Windows UI의 기존 촬영본을 유지합니다. 이전 버전이 참조하는 이미지는 보존했습니다.

## 검증과 공개 상태

2026-10-20에 [v1.3.5](https://github.com/poyal/passport/releases/tag/v1.3.5)를 **Mac ARM64만 공개**했습니다. 설치 파일의 소스와 태그는 `6c23037ba5eed37327c8cf892939dd7f6131bf46`입니다. 게시 결과는 `published-and-download-verified`이며, 공개 후 인증 없는 별도 다운로드로 DMG·`SHA256SUMS.txt`의 크기와 SHA-256을 다시 확인했습니다. 이 기록·최신 다운로드 안내·촬영본을 반영하는 후속 문서 커밋은 배포 바이너리의 소스와 구분합니다.

Windows 1.3.5는 이번 작업에서 검증·빌드·게시하지 않았습니다. Windows 공개 설치본은 [v1.3.3](https://github.com/poyal/passport/releases/tag/v1.3.3)을 유지하며 기존 EXE의 자산 ID·크기·SHA-256이 바뀌지 않았음을 확인했습니다. 사용자 설치 앱과 실제 앱 데이터는 교체하지 않았습니다.

### Windows 1.3.5 추가 게시 준비

2026-10-20 후속 Windows 검증에서 원래 `v1.3.5` 소스는 단위·통합 270개와 배포 정책 74개를 통과했지만, 소스 GUI의 세션 로그 스크롤 검사에서 실패했습니다. Windows 11의 150% 배율·1024×680 창에서 로그 내용의 높이가 0이 되는 것을 격리 데이터로 재현했습니다. 실패 manifest는 게시에 사용하지 않습니다.

사용자는 결함 수정에 새 버전이 필요하다는 기존 규칙을 안내받은 뒤 수정본도 **1.3.5로 게시**하도록 명시했습니다. Windows 수정본은 기존 Mac `v1.3.5` 태그·DMG를 유지하고 `v1.3.5-win-x64` 소스 태그를 따로 사용합니다. 수정은 좁은 로그 화면의 조회 범위·여백 배치와 최소 읽기 높이 보장, 해당 GUI 검사, Mac 자산을 고정하는 제한된 게시 예외입니다. 최소·일반·큰 창과 두 테마의 로그 스크롤 재현 검사는 통과했으며 전체 정식 검증·설치 파일·공개 결과는 아직 확정 전입니다.

실제 Codex·Claude CLI에서 앱 완전 종료·재시작 전후의 동일 대화 ID, 다음 메시지, 실행 옵션 보존, 빈 Claude 세션 재실행을 확인했습니다. Electron의 HOME·USERPROFILE과 정상 OS safeStorage를 유지했고, CLI 설정·대화 폴더와 모델 응답만 격리했습니다.

## 검증 중 확인한 조건

- 새 ad-hoc 설치본의 실제 safeStorage 호출이 macOS 키체인 승인 대기에서 멈추는 것을 네이티브 스택으로 확인했습니다. 사용자가 OS 창에서 승인한 뒤 동일 후보의 실제 AI 재시작 검사를 통과했고, 최종 정식 검증에서도 소스·설치본 모두 통과했습니다. 평문 mock이나 키체인 초기화로 우회하지 않았습니다.
- 데스크톱 알림 시험의 문자별 입력에 한글 조합·물리 키 상태가 섞여 반환 표시가 달라졌습니다. 시험용 zsh 설정과 준비 프롬프트를 분리하고 제어 명령을 한 번에 전달하도록 보완했습니다. 실제 네이티브 포커스·전경 알림 억제·배경 알림 표시 검증은 유지했습니다. 이 시험 수정은 앱의 키보드·IME 동작을 바꾸지 않습니다.
- 이전 후보 실행에서 Electron 종료 10초 초과가 한 번 발생했습니다. 별도 단독·전체 데스크톱 진단에서는 재현되지 않아 원인은 확정하지 않았으며, 최종 정식 실행의 모든 종료는 제한 안에 통과했습니다. 이전 실패 기록을 성공으로 변경하지 않았습니다.

## 별도 확인 범위와 제한

- 자동 AI 아이콘은 인증된 기존 실행 연동에 의존합니다. 임의 프로세스 검색·연동되지 않은 CLI 감지는 하지 않습니다. 직접 지정한 아이콘과 템플릿의 저장 아이콘을 우선합니다.
- 실제 AI CLI 검사의 모델 응답은 루프백 fixture입니다. 유료 API·실제 로그인·외부 AI 서비스 검증과 구분합니다.
- Windows 11 실기, macOS 14 실기, 물리 IME, OS 알림 표시, 다른 PC의 LAN, 깨끗한 계정의 설치·제거·업그레이드, Docker·장시간 부하는 별도 확인 대상입니다.
