# v0.1 구현·검증 기록

이 문서는 v0.1 당시의 기록이다. 현재 구현과 플랫폼별 상태는 [최신 검증 기록](../verification.md)을 참고한다.

검증일: 2026-09-29. 개발 장비는 Apple M1 Max(10코어), 64GB RAM, macOS 27.0, arm64다. 테스트는 별도의 임시 데이터 폴더와 루프백 서버를 사용하며 실제 사용자 서버에는 연결하지 않았다.

## 구현 범위

- 한국어 호스트·그룹·태그·인증 프로필 관리, 검색·즐겨찾기·최근 접속.
- 비밀번호·암호화 개인 키 SSH, 호스트 지문 확인, 탭·드래그 분할·크기 조절·집중 보기·배치 저장.
- 좌우 독립 로컬/SFTP/FTP/명시적 FTPS 탐색기, 컨텍스트 메뉴, 파일 관리, SFTP 기본 권한 변경.
- 로컬↔원격·원격↔원격 스트리밍 전송, 충돌 처리·취소·재시도·대기열.
- 테마 12종, 시스템 폰트·기본 JetBrains Mono, 전역/호스트/세션 외형 설정.
- 스니펫을 선택 창 또는 현재 작업 탭에 미리보기 후 붙여넣기. Enter 자동 전송 없음.
- SSH config·Passport 파일 가져오기, 비밀값 제외 내보내기·선택적 암호화 내보내기, 로컬 백업.
- 승인된 v2 아이콘과 다크·라이트·시스템 외형.

v0.2·v0.3 기능은 [제품 계획](../plan.md)의 후속 로드맵이다. 업데이트, 클라우드 동기화 및 사용자 제외 기능은 구현하지 않았다.

Mac 설치본은 `release/Passport-0.1.0-arm64.dmg`다. 개발용 ad-hoc 서명이며 공개 배포용 Developer ID 서명·공증은 포함하지 않는다. 최소 지원 목표는 macOS 14지만 현재 시험은 macOS 27에서 수행했다. Windows 설치본이나 macOS 14 실기기 검증 완료를 의미하지 않는다.

최종 DMG는 약 145MiB이며 실행 파일의 `arm64` 형식과 `codesign --verify --deep --strict` 검증을 통과했다. 패키지 실행에서도 `arch=arm64`, 스키마 1, 시스템 폰트 247개, 렌더러 Node 격리를 확인했다. SHA-256: `e6f9524bb8191c5cc180740e252ca8da03f9447970a149ac8c86fb6ef3ac2b49`.

## 자동 검증

최종 타입 검사 및 단위/프로토콜 통합 결과는 **33개 통과·부하 시험 1개 기본 제외**, Electron GUI는 **3개 통과**다. 부하 시험은 아래의 별도 실행에서 확인했다.

| 항목                | 확인한 동작                                                                                                                                                                                                      |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 타입 검사·단위/통합 | 분할 트리와 이동·상한, 붙여넣기 원문, 가져오기 중복·암호화·손상/암호 오류, SQLite와 비밀값 분리·백업, 인증 메타데이터 변경, 재연결 후 전송 재시도.                                                               |
| 실제 SSH/SFTP       | 루프백 ssh2 서버의 비밀번호·암호화 키 인증, 최초 지문 등록·변경 차단, 입력/출력/PTY 크기, 로컬→SFTP→별도 SFTP 연결 복사와 권한 변경.                                                                             |
| 실제 FTP/FTPS       | pyftpdlib 서버의 passive FTP, 별도 연결 간 복사, 명시적 TLS, 신뢰하지 않는 인증서 거절, 시험 CA를 신뢰하는 연결의 전송. 운영 인증서 검증은 비활성화하지 않음.                                                    |
| Electron GUI        | 호스트 저장·재시작 보존, 실제 SSH, 분할·집중 보기·탭 분리·드래그 이동 시 세션 유지, 12종 테마, 다른 탭 제외 스니펫 붙여넣기, 다크/라이트, 독립 파일 패널·컨텍스트 메뉴·복사 큐, 시작·목록 조회 시 키체인 미호출. |
| 패키지 실행         | 개발 서버 없이 패키지 실행, 새 프로필 생성·스키마 1·폰트 247개, 렌더러 `require` 미노출.                                                                                                                         |

시험 인증 정보·키·서버는 테스트 실행 중 생성하며 종료 후 정리한다. GUI의 최초 지문 확인 대화상자만 테스트에서 자동 승인한다. 제품에서는 사용자가 직접 승인해야 한다.

## 성능 측정

**16개 SSH 터미널, 10분 출력 시험: 통과.** 호스트 500개를 저장하고 실제 연결 16개를 4×4로 표시했다. 각 연결에 100ms마다 10KiB를 전송했다. 관측 전송량은 연결당 60,825,600바이트이며 스케줄링 오차를 고려한 95% 처리량 기준을 통과했다.

- 측정 시간: 600,001ms.
- 입력 루프백 응답 p95: 12.3ms(목표 100ms 미만).
- Electron 프로세스 작업 집합 합계: 최대 1,163MiB, 마지막 1,133MiB.
- [원시 측정 결과](../benchmarks/terminal-stress-v0.1.json).

응답 시간은 렌더러 IPC→로컬 SSH 서버→출력 이벤트 수신을 측정한다. 실제 키보드 입력부터 화면에 그려지는 시간이나 외부 네트워크 지연을 분리한 값은 아니다. 메모리는 Electron 프로세스의 작업 집합 합계이며 고유 물리 메모리와 같지 않을 수 있다. 500개 호스트 검색/스크롤과 32개 동시 연결의 별도 부하 측정은 남아 있다.

**4GiB 파일과 작은 파일 10,000개 전송 시험: 통과(15.61초).** 로컬 어댑터 간 스트리밍 복사로 4GiB 파일 크기·SHA-256 일치, RSS 증가 512MiB 미만, 파일 10,000개와 표본 원문을 확인했다. 원본 대용량 파일은 sparse 파일로 만들었다. 이 결과는 WAN·실제 원격 서버의 4GiB 전송 속도를 의미하지 않는다.

## 재현 명령

```sh
npm ci
npm run check
npm run test:e2e
```

FTP/FTPS 통합 테스트는 Python 환경과 OpenSSL이 있어야 실행되며 `FTP_TEST_PYTHON` 미지정 시 두 테스트를 건너뛴다.

```sh
python3 -m venv /tmp/passport-test-venv
/tmp/passport-test-venv/bin/pip install -r tests/fixtures/requirements.txt
FTP_TEST_PYTHON=/tmp/passport-test-venv/bin/python npm run check
```

부하 시험은 기본 테스트에서 건너뛰며 명시적으로 실행한다. 4GiB 시험에는 임시 디스크 공간이 필요하다. GUI 부하 시험은 10분 동안 실행된다.

```sh
PASSPORT_STRESS=1 node scripts/test.mjs tests/stress.test.ts
npm run build
PASSPORT_UI_STRESS=1 npx playwright test tests/e2e/stress.spec.ts
npm run dist:mac
node scripts/packaged-smoke.mjs release/mac-arm64/Passport.app/Contents/MacOS/Passport
```

Windows에서는 Windows 터미널에서 `npm ci`, `npm run check`, `npm run test:e2e`, `npm run dist:win`을 실행한다. [수동 CI](../../.github/workflows/desktop.yml)는 Windows x64와 Mac arm64에서 같은 검증과 패키징을 수행하도록 구성했으며 이 작업 중 원격 실행하지 않았다.

## 남은 실환경 검증

- 실제 macOS 키체인·Windows DPAPI의 비밀값 저장·복원과 권한 흐름. 단위 테스트는 테스트 Vault로 저장 정책을 검증했다. 재빌드한 ad-hoc 앱에서 키체인 접근 대기를 관찰하여, 시작·목록 조회에서 비밀 저장소를 호출하지 않도록 수정했다. 인증 정보 저장·사용 시에는 OS가 접근 허용을 요청할 수 있다.

- Windows 11 빌드·EXE 설치·재실행·기기 간 내보내기/가져오기, macOS 14 최소 버전.
- 두 OS의 한글 IME, 100/150/200% 배율, 네이티브 파일 대화상자와 키보드/보조 클릭 접근성 전체 확인.
- OpenSSH의 실제 sh/bash/zsh·vim/top, Alpine·Ubuntu·Rocky·구형 CentOS와의 호환성. 현재 프로토콜 테스트 서버는 ssh2이며 이 배포판들을 실행한 결과가 아니다.
- 실제 네트워크 단절·권한 거절·대소문자 파일 시스템 차이·장시간 전송. 취소 중 서버 연결까지 끊기면 `.passport-*.part` 정리가 실패할 수 있어 큐의 정리 안내를 확인해야 한다.
- 12종 테마의 전체 ANSI/트루컬러·넓은 문자·긴 줄·대체 화면, 모든 화면의 대비 및 1024×680 최소 크기 조작 점검.
